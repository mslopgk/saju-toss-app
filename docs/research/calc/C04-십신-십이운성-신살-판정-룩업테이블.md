## 0. 기본 상수 (index 규약)

모든 코드에서 아래 인덱스 규약을 고정한다. **인덱스가 흔들리면 전 표가 틀어진다.**

```js
const GAN = ["甲","乙","丙","丁","戊","己","庚","辛","壬","癸"];         // 0..9
const ZHI = ["子","丑","寅","卯","辰","巳","午","未","申","酉","戌","亥"]; // 0..11

const GAN_KO = ["갑","을","병","정","무","기","경","신","임","계"];
const ZHI_KO = ["자","축","인","묘","진","사","오","미","신","유","술","해"];
```

## 1. 오행 생극 기본 함수

```js
const SHENG = { 木:"火", 火:"土", 土:"金", 金:"水", 水:"木" };  // 生: key가 value를 생한다
const KE    = { 木:"土", 土:"水", 水:"火", 火:"金", 金:"木" };  // 剋: key가 value를 극한다
```

| 관계 | 조건식 | 명칭 |
|---|---|---|
| 나와 같은 오행 | `EL(target) === EL(day)` | 比劫 (비겁) |
| 내가 생하는 오행 | `SHENG[EL(day)] === EL(target)` | 食傷 (식상) |
| 내가 극하는 오행 | `KE[EL(day)] === EL(target)` | 財星 (재성) |
| 나를 극하는 오행 | `KE[EL(target)] === EL(day)` | 官殺 (관살) |
| 나를 생하는 오행 | `SHENG[EL(target)] === EL(day)` | 印星 (인성) |

## 2. 십신(十神) 도출 알고리즘

### 2-1. 확정 규칙

```
입력: dayGan (일간, 천간 1글자), target (대상 천간 1글자)
출력: 십신 1개

R1. de = 오행(dayGan), te = 오행(target)
R2. same = (음양(dayGan) === 음양(target))        // 동성 여부
R3. 분기:
      te === de          →  same ? 比肩(비견) : 劫財(겁재)
      SHENG[de] === te   →  same ? 食神(식신) : 傷官(상관)
      KE[de]    === te   →  same ? 偏財(편재) : 正財(정재)
      KE[te]    === de   →  same ? 偏官(편관, =七殺) : 正官(정관)
      SHENG[te] === de   →  same ? 偏印(편인, =梟神) : 正印(정인)
```

**핵심 원칙 한 줄**: `同性 → 偏(편) / 異性 → 正(정)`. 단 비겁·식상은 명칭이 偏/正이 아니라 비견·겁재 / 식신·상관으로 불릴 뿐 원리는 동일하다.
비겁은 **同性=비견, 異性=겁재**, 식상은 **同性=식신, 異性=상관**으로 "同性이 순한 쪽" 배치이고,
재·관·인은 **同性=偏(편재/편관/편인), 異性=正(정재/정관/정인)** 으로 "異性이 순한 쪽" 배치라는 점만 외우면 된다.

```js
function tenGod(dayGan, target) {
  const de = GAN_EL[dayGan], te = GAN_EL[target];
  const same = (GAN.indexOf(dayGan) % 2) === (GAN.indexOf(target) % 2);
  if (te === de)         return same ? "비견" : "겁재";
  if (SHENG[de] === te)  return same ? "식신" : "상관";
  if (KE[de]    === te)  return same ? "편재" : "정재";
  if (KE[te]    === de)  return same ? "편관" : "정관";
  if (SHENG[te] === de)  return same ? "편인" : "정인";
}
```

### 5-1. 확정 알고리즘 (lunar-javascript `_getDiShi` 이식)

```js
const CS = ["장생","목욕","관대","건록","제왕","쇠","병","사","묘","절","태","양"];
const CS_OFFSET = { 甲:1, 乙:6, 丙:10, 丁:9, 戊:10, 己:9, 庚:7, 辛:0, 壬:4, 癸:3 };

function unseong(gan, zhi) {
  const zi = ZHI.indexOf(zhi);
  const yang = GAN.indexOf(gan) % 2 === 0;
  const idx = ((CS_OFFSET[gan] + (yang ? zi : -zi)) % 12 + 12) % 12;
  return CS[idx];
}
```

원문(`6tail/lunar-javascript/lunar.js`):

```js
CHANG_SHENG_OFFSET: {
  '甲':1, '丙':10, '戊':10, '庚':7, '壬':4,
  '乙':6, '丁':9,  '己':9,  '辛':0, '癸':3
},
CHANG_SHENG: ['长生','沐浴','冠带','临官','帝旺','衰','病','死','墓','绝','胎','养'],

_getDiShi: function (zhiIndex) {
  var offset = LunarUtil.CHANG_SHENG_OFFSET[this.getDayGan()];
  var index = offset + (this.getDayGanIndex() % 2 === 0 ? zhiIndex : -zhiIndex);
  if (index >= 12) { index -= 12; }
  if (index < 0)   { index += 12; }
  return LunarUtil.CHANG_SHENG[index];
}
```

**offset 유도식** (하드코딩 대신 계산하고 싶을 때):

```
장생지 = {甲:亥, 乙:午, 丙:寅, 丁:酉, 戊:寅, 己:酉, 庚:巳, 辛:子, 壬:申, 癸:卯}
陽干:  offset = (12 - ZHI.indexOf(장생지)) % 12
陰干:  offset =        ZHI.indexOf(장생지)
```
검산: 甲 장생 亥(11) → (12-11)%12 = 1 ✓ / 乙 장생 午(6) → 6 ✓ / 辛 장생 子(0) → 0 ✓

**양간 순행 / 음간 역행 규칙**
- 陽干(甲丙戊庚壬): 장생지에서 지지 순서(子→丑→…→亥) **정방향**으로 12운성을 배치
- 陰干(乙丁己辛癸): 장생지에서 지지 순서 **역방향**으로 배치

### 5-3. ⚠️유파차이 — 음간 역행 vs 음간 순행(포태동일)


**본 앱 채택**: A안(음간 역행)을 기본값. 설정에 `unseongSchool: "reverse" | "sameAsYang"` 플래그를 두고 기본 `"reverse"`.

## 6. 십이신살(十二神煞)

### 6-1. 확정 알고리즘

```
기준지(base) = 연지(전통) 또는 일지(현대)   ← ⚠️유파차이, 본 앱은 "연지·일지 둘 다 산출"
1. base가 속한 삼합국을 찾는다.  삼합국 = {水:申子辰, 火:寅午戌, 金:巳酉丑, 木:亥卯未}
2. 그 삼합국의 墓地(세 번째 글자, 辰/戌/丑/未)의 다음 지지 = 겁살 위치 start
3. start부터 지지 순서대로 12신살을 순차 배치:
   [겁살, 재살, 천살, 지살, 연살, 월살, 망신살, 장성살, 반안살, 역마살, 육해살, 화개살]
4. 대상 지지 t의 신살 = SAL12[ (idx(t) - start + 12) % 12 ]
```

```js
const SAL12 = ["겁살","재살","천살","지살","연살","월살","망신살","장성살","반안살","역마살","육해살","화개살"];
const SAMHAP = { 水:["申","子","辰"], 火:["寅","午","戌"], 金:["巳","酉","丑"], 木:["亥","卯","未"] };

function sinsal12(baseZhi, targetZhi) {
  const grp   = Object.values(SAMHAP).find(a => a.includes(baseZhi));
  const start = (ZHI.indexOf(grp[2]) + 1) % 12;              // 墓地 + 1 = 겁살
  const off   = ((ZHI.indexOf(targetZhi) - start) % 12 + 12) % 12;
  return SAL12[off];
}
```

**항등식 검산** (구현 자체 테스트로 쓸 것):
- 지살 = 삼합의 生地(첫 글자) — 申子辰 → 지살 申 ✓
- 장성살 = 삼합의 旺地(가운데) — 申子辰 → 장성 子 ✓
- 화개살 = 삼합의 墓地(끝) — 申子辰 → 화개 辰 ✓
- 역마살 = 生地의 충(沖) — 申의 충 = 寅 ✓ (`申子辰马寅`)
- 연살(도화) = 旺地의 다음... 이 아니라 **旺地의 沐浴地** — 申子辰 → 연살 酉 ✓
- 겁살 = 墓地 + 1 = 절지 — 申子辰 → 겁살 巳 ✓

### 7-5. 홍염살(紅艷煞) — 일간 → 지지

| 일간 | 甲 | 乙 | 丙 | 丁 | 戊 | 己 | 庚 | 辛 | 壬 | 癸 |

| **A안(본 앱, 한국 통용)** | 午 | 午 | 寅 | 未 | 辰 | 辰 | 戌 | 酉 | 子 | 申 |

> ⚠️유파차이 — **3안**이며 乙·己·庚·癸 4칸이 갈린다.
>
> **C20 재정정 (C16 §5-1의 판정을 철회)**: 종전 이 절이 적은 `甲乙午申庚見馬`는 **1자 오기(`馬`→`戌`)였을 뿐 출처는 실재한다.** 실제 원문은 神峰通考 卷四 §271 「紅艷殺」 歌訣의 `甲乙午申庚見戌，世間只是眾人妻` 이다(ctext urn:ctp:wb627586, chapter=472359).
> C16 §5-1은 이를 「어느 자료에도 없는 문자열」로 단정했으나 **오판**이며, C20에서 1차 한문 원전 2종을 확보해 정정했다.
>
> 확보된 1차 원전 2종 (C20 §7):
> - **三命通會 卷三 總論諸神煞 §28 (査法)**: `甲乙逢午、丙寅、丁未、戊子、己辰、庚戌、辛酉、壬巳、癸申，為紅艷煞，女命最忌之。`
> - **神峰通考 卷四 §271 (歌訣)**: `多情多欲少人知，六丙逢寅辛見雞。癸臨申上丁見未…甲乙午申庚見戌，世間只是眾人妻。戊己怕辰壬怕子…`
>
> 채택 A안은 神峰通考 歌訣과 **10칸 중 9칸 일치**(乙만 상이: A안 午 / 歌訣 申)하며, 乙=午 는 三命通會 査法 `甲乙逢午` 를 근거로 한다. 두 원전은 乙·戊·壬 에서 실제로 이견이 있다.
>
> - B안 원문(리터럴 확인): `甲——午，乙——申，丙——寅，丁——未，戊——辰。己——辰，庚——申，辛——酉，壬——子，癸——戌。`
> - C안 원문(리터럴 확인): `多情多欲少人知，六丙逢寅辛见鸡，癸临申上丁见未 … 甲午乙申庚怕戍，世间只是众人妻，戊己龙蛇壬怕子，花前月下也投机。`
>   (`六丙逢寅`=丙寅 / `辛见鸡`=辛酉 / `癸临申上`=癸申 / `丁见未`=丁未 / `甲午` / `乙申` / `庚怕戍`=庚戌 / `戊己龙蛇`=戊辰·己巳 / `壬怕子`=壬子)

> **결과 차이**: 乙 일간에 申이 있을 때 A안은 홍염 미성립, B·C안은 성립. 홍염은 "이성운/매력" 텍스트를 켜므로 체감 차이가 크다.

### 7-9. 공망(空亡 / 旬中空亡)

**알고리즘** (60갑자에서 천간이 모자라 남는 2지지):

```js
function gongmang(ganzhi) {              // ganzhi = "甲子" 형태
  const gi = GAN.indexOf(ganzhi[0]);
  const zi = ZHI.indexOf(ganzhi[1]);
  const xunIndex = Math.floor(((((gi - zi) % 12) + 12) % 12) / 2);

}
```

## 8. 십이운성·신살 통합 판정 의사코드

```js
function analyzeSinsal(pillars) {
  // pillars = { year:"庚午", month:"辛巳", day:"丙寅", hour:"癸巳" }
  const order = ["year","month","day","hour"];
  const gz    = order.map(k => pillars[k]);
  const gans  = gz.map(s => s[0]);
  const zhis  = gz.map(s => s[1]);
  const dayGan = pillars.day[0], yearZhi = pillars.year[1], dayZhi = pillars.day[1];

  const result = { tenGods: {}, unseong: {}, sinsal12: {}, sinsal: [], relations: [] };

  // 1) 십신
  order.forEach((k, i) => {
    result.tenGods[k] = {
      gan: (k === "day") ? "일간" : tenGod(dayGan, gans[i]),
      zhi: tenGodOfZhi(dayGan, zhis[i]),
      zhiAll: hiddenStems(zhis[i]).map(h => ({ gan: h, god: tenGod(dayGan, h) }))
    };
  });

  // 2) 십이운성 (일간 거법)
  order.forEach((k, i) => { result.unseong[k] = unseong(dayGan, zhis[i]); });

  // 3) 십이신살 (연지 기준 + 일지 기준 둘 다)
  order.forEach((k, i) => {
    result.sinsal12[k] = { byYear: sinsal12(yearZhi, zhis[i]), byDay: sinsal12(dayZhi, zhis[i]) };
  });

  // 4) 일간 기준 신살
  for (const [name, table] of Object.entries(DATA.byDayStem)) {
    const hits = order.filter((k, i) => table[dayGan].includes(zhis[i]));
    if (hits.length) result.sinsal.push({ name, pillars: hits, basis: "일간" });
  }
  // 5) 연지 기준 신살
  for (const [name, table] of Object.entries(DATA.byYearBranch)) {
    const hits = order.filter((k, i) => table[yearZhi] === zhis[i]);
    if (hits.length) result.sinsal.push({ name, pillars: hits, basis: "연지" });
  }
  // 6) 간지 매칭 신살  ← C16 §5-3에서 수정: 백호대살·괴강은 "일주 선행 게이트"가 있다
  //    ko.wikipedia 괴강: "일주가 …이면 괴강살이 온다. 그 상태에서 연/월/시주에 있다면 그 주에도"
  //    yyzfs 57번:        "魁罡格在日柱方能入格，其他三格不算"
  //    ko.wikipedia 백호: "일주가 …이면 백호대살이 온다. 또한 그 상태에서 …"
  const GATE = { 백호대살: "dayPillarFirst", 괴강: "dayPillarFirst" };   // 금신 등은 게이트 없음
  for (const [name, list] of Object.entries(DATA.byPillarGanzhi)) {
    if (GATE[name] === "dayPillarFirst" && !list.includes(pillars.day)) continue;  // 게이트
    const hits = order.filter((k, i) => list.includes(gz[i]));
    if (hits.length) result.sinsal.push({ name, pillars: hits, basis: "간지" });
  }
  // ⚠️유파차이 — 한국 실무 다수는 백호를 각 주 독립 판정(anyPillar)한다. 플래그로 노출할 것.
  // 반례: 壬戌 庚戌 甲子 丁卯 → anyPillar면 백호[연]·괴강[연,월], dayPillarFirst면 둘 다 미성립.
  //       C04 §12-1 점수식으로 환산 시 sinsalScore 34 vs 50 (16점 차).
  // 7) 공망
  const km = gongmang(pillars.day);
  const kongHits = order.filter((k, i) => k !== "day" && km.includes(zhis[i]));
  if (kongHits.length) result.sinsal.push({ name: "공망", pillars: kongHits, basis: "일주", detail: km });

  // 8) 삼재 (해당 연도 판정은 별도 호출)
  result.samjae = SAMJAE[yearZhi];

  // 9) 지지/천간 관계
  result.relations = findRelations(gans, zhis, order);
  return result;
}
```

## 12. 앱 점수화 연결 규격 (결정적)

```js
const SINSAL_SCORE = {
  천을귀인:+8, 문창귀인:+5, 학당귀인:+4, 금여:+4, 암록:+4, 건록:+3,

  겁살:-3, 재살:-3, 천살:-2, 월살:-2, 망신살:-2, 육해살:-2
};

// 12-2) 기둥 가중치 (같은 신살도 어느 기둥에 붙는지로 강도가 달라진다)
const PILLAR_WEIGHT = { year: 0.8, month: 1.2, day: 1.5, hour: 1.0 };

// 12-3) 최종
function sinsalScore(hits) {           // hits = [{name, pillars:["month","day"]}]
  let raw = 0;
  for (const h of hits)
    for (const p of h.pillars)
      raw += (SINSAL_SCORE[h.name] ?? 0) * PILLAR_WEIGHT[p];
  return Math.max(0, Math.min(100, 50 + raw * 2));   // 50 기준 ±
}

// 12-4) 십이운성 에너지 (일지 십이운성을 주축으로)
function unseongEnergy(dayGan, zhis) {
  const E = { 장생:60, 목욕:45, 관대:75, 건록:90, 제왕:100, 쇠:55, 병:35, 사:20, 묘:15, 절:10, 태:25, 양:40 };
  const w = [0.8, 1.2, 1.5, 1.0];     // 연월일시
  return zhis.reduce((s, z, i) => s + E[unseong(dayGan, z)] * w[i], 0) / 4.5;
}
```
