## 2. 절기 시각 계산 (결정적 구현)

태양의 **겉보기 황경(apparent geocentric ecliptic longitude)** λ 가 목표값을 지나는 시각을 뉴턴법으로 찾는다.

```js
// 방법 A (권장): astronomy-engine — KASI/중국 만세력 대비 오차 < 15초
const A = require('astronomy-engine');
function jieDateUTC(year, i){
  // JIE[i].lon = 315,345,15,...  JIE[i].mon = 탐색 시작 월
  const t = A.SearchSunLongitude(JIE[i].lon, new Date(Date.UTC(year, JIE[i].mon-1, 1)), 40);
  return t.date;                     // UTC
}
function jieDateKST(year, i){ return new Date(jieDateUTC(year,i).getTime() + 9*3600*1000); }
```

## 3. 대운 순행/역행 판정표 (4가지 조합 — 전부)

**판정 기준은 "연간(年干)의 음양" × "성별"이다. 연지(年支)가 아니다.**
그리고 그 연간은 **입춘으로 확정된 사주년**의 연간이다(양력 1/1~입춘 전 출생자는 전년도 간지).

`lunar-python/eightchar/Yun.py` 원문:

```python
yang = 0 == self.__lunar.getYearGanIndexExact() % 2   # Exact = 입춘 기준
man  = 1 == gender
self.__forward = (yang and man) or (not yang and not man)
```

| # | 연간 음양 | 성별 | 통칭 | 방향 | 대운 간지 진행 | 기준 節 |
|---|----------|------|------|------|---------------|---------|
| 1 | 양(甲丙戊庚壬) | 남 | 양남(陽男) | **순행(順行)** | 월주 +1, +2, +3 … | **다음 節** (미래절) |
| 2 | 양(甲丙戊庚壬) | 여 | 양녀(陽女) | **역행(逆行)** | 월주 −1, −2, −3 … | **직전 節** (과거절) |
| 3 | 음(乙丁己辛癸) | 남 | 음남(陰男) | **역행(逆行)** | 월주 −1, −2, −3 … | **직전 節** (과거절) |
| 4 | 음(乙丁己辛癸) | 여 | 음녀(陰女) | **순행(順行)** | 월주 +1, +2, +3 … | **다음 節** (미래절) |

```js
/** gender: 1=남, 0=여 */
function isForward(yearGanIdx, gender){
  const yang = (yearGanIdx % 2 === 0);
  const man  = (gender === 1);
  return (yang && man) || (!yang && !man);   // XNOR
}
```

⚠️**유파차이 — 성별 입력**: 트랜스젠더/논바이너리 입력 대응이 필요하면 "명리상 성별"을 별도 필드로 받아야 한다. 방향이 뒤집히면 대운 간지 전체가 완전히 달라진다(예: 케이스 A 을유↔계미).

## 4. 대운수(大運數) 계산 — 정확 공식

### 4.1 구간 정의

```
forward(순행)  : start = 출생시각,        end = 다음 節 입절시각
backward(역행) : start = 직전 節 입절시각, end = 출생시각
Δ = end - start   (분 단위 정수)
```

`Yun.py` 원문:
```python
prev_jie = self.__lunar.getPrevJie()
next_jie = self.__lunar.getNextJie()
current  = self.__lunar.getSolar()
start = current if self.__forward else prev_jie.getSolar()
end   = next_jie.getSolar() if self.__forward else current
```

### 4.2 환산 상수표 (전부)

| 실제 경과 | 대운 환산 | 분(minute) 환산 | 유도 |
|-----------|-----------|-----------------|------|
| 3일 | **1년** | 4320분 = 1년 | 1개월(節~節) ≈ 30일 ↔ 대운 10년 → 30:10 = 3:1 |
| 1일 | **4개월** | 1440분 = 4개월 | 1년/3 = 4개월 |
| 1시진(2시간) | **10일** | 120분 = 10일 | 4개월(120일)/12시진 = 10일 |
| 1시간 | **5일** | 60분 = 5일 | 10일/2 |
| 12분 | **1일** | 12분 = 1일 | 120분/10일 |
| 6시간 | **1개월** | 360분 = 1개월 | 30일 × 12분 |
| 1분 | **2시간** | 1분 = 2시간 | 24h/12분 |

### 4.3 계산 방식 4종 — **결과가 다르다**

#### (A) 분 단위 정밀식 — `lunar-*` sect=2, 본 앱 채택
```js
let m = totalMinutes;
const year  = Math.floor(m / 4320); m -= year * 4320;   // 3일 = 1년
const month = Math.floor(m / 360);  m -= month * 360;   // 6시간 = 1개월
const day   = Math.floor(m / 12);   m -= day * 12;      // 12분 = 1일
const hour  = m * 2;                                    // 1분 = 2시간
// 교운일시 = 출생일시 + year년 + month월 + day일 + hour시간
```
원문(`Yun.py`, `sect == 2`):
```python
minutes = end.subtractMinute(start)
year = int(minutes / 4320);  minutes -= year * 4320
month = int(minutes / 360);  minutes -= month * 360
day = int(minutes / 12);     minutes -= day * 12
hour = minutes * 2
```

#### (B) 시진(2시간) 단위식 — `lunar-*` sect=1 (라이브러리 **기본값**)
```python
end_time_zhi_index   = 11 if end.getHour() == 23 else getTimeZhiIndex(end_hhmm)
start_time_zhi_index = 11 if start.getHour() == 23 else getTimeZhiIndex(start_hhmm)
hour_diff = end_time_zhi_index - start_time_zhi_index
day_diff  = end.subtract(start)            # 달력일 차
if hour_diff < 0:
    hour_diff += 12
    day_diff  -= 1
month_diff = int(hour_diff * 10 / 30)
month = day_diff * 4 + month_diff
day   = hour_diff * 10 - month_diff * 30
year  = int(month / 12); month = month - year * 12
```
→ 분 정보를 버리고 시진(2h)으로 절삭. **최대 2시간(=10일 교운) 오차.**

#### (C) 한국 전통 대운수 — 정수 일수 ÷ 3, 나머지 1 버림 / 2 올림
```js
const days = Math.floor(totalMinutes / 1440);
const rem  = days % 3;
const num  = Math.floor(days / 3) + (rem === 2 ? 1 : 0);
// rem === 0 → 그대로,  rem === 1 → 버림,  rem === 2 → +1
```
KNS뉴스통신 [제31강 대운수 산출법] 원문 규칙: **나머지 1은 버림, 나머지 2는 올림(+1), 나머지 없으면 그대로.**

#### (D) 반올림식 — `round(exactDays / 3)`
```js
const num = Math.round(totalMinutes / 1440 / 3);
```
brunch/사주스터디 계열이 소개하는 "소수점 반올림" 방식.

### 6.2 월운 — 節 기준 + 五虎遁

```js
// 월지 = 직전 節이 여는 지지
// 월간 = 五虎遁: (연간 % 5) * 2 + 2 + (월지 - 寅(2) mod 12)  (mod 10)
function wolwoonAt(date){
  const prev = surroundingJie(date).prev;
  const sajuYear = (prev.i === 11) ? prev.y - 1 : prev.y;      // 소한은 전년 사주
  const yearGan  = sewoonIndexOfYear(sajuYear) % 10;
  const zhi = JIE_ZHI_INDEX[prev.i];
  const gan = ((yearGan % 5) * 2 + 2 + ((zhi - 2 + 12) % 12)) % 10;
  return { ganji: gz(idxOf(gan, zhi)), jie: JIE[prev.i].name, jieDate: prev.d };
}
```

### 6.3 일운(일진)

```js
function julianDayNumber(y, m, d){
  if (m <= 2) { y -= 1; m += 12; }
  const a = Math.floor(y / 100), b = 2 - a + Math.floor(a / 4);
  return Math.floor(365.25*(y+4716)) + Math.floor(30.6001*(m+1)) + d + b - 1524;
}
/** 0 = 갑자.  기준 검증: 1949-10-01 = 甲子일 */
function dayIndex(y, m, d){ return ((julianDayNumber(y,m,d) - 11) % 60 + 60) % 60; }
```

⚠️**유파차이 — 야자시(夜子時)**: 23:00~23:59 를 ① 당일 자시로 볼지 ② 익일 자시로 볼지.
- `lunar-*` 기본(sect=2)은 **일주는 당일 유지, 시주 천간만 익일 일간으로 遁**한다 → 1970-12-31 23:30 의 시주가 `丙子`(당일 乙酉 기준) 대신 `戊子`(익일 丙戌 기준)가 된다.
- 본 구현은 `opt.lateZiAsNextDay`(일주까지 넘김) / `opt.lateZiHourGanFromNextDay`(시간만 넘김) 두 플래그로 분리 제공.

```js
function analyze(natalGZ /* [연,월,일,시] 0..59 */, luckGZ /* 0..59 */){
  const lg = luckGZ % 10, lz = luckGZ % 12;
  const events = [];
  natalGZ.forEach((g, i) => {
    const ng = g % 10, nz = g % 12;
    // ---- 천간 1:1 ----
    if (ganHap(ng, lg))   events.push({type:'천간합',  pos:POS[i], weight:+6});
    if (ganChung(ng, lg)) events.push({type:'천간충',  pos:POS[i], weight:-8});
    else if (ganKe(lg, ng)) events.push({type:'천간극', pos:POS[i], weight:-3});
    // ---- 지지 1:1 ----
    if (zhiYukhap(nz, lz)) events.push({type:'지지육합', pos:POS[i], weight:+7});
    if (zhiChung(nz, lz))  events.push({type:'지지충',  pos:POS[i], weight:-10});
    if (inPairList(PA, nz, lz))     events.push({type:'파',   pos:POS[i], weight:-3});
    if (inPairList(HAE, nz, lz))    events.push({type:'해',   pos:POS[i], weight:-4});
    if (inPairList(WONJIN, nz, lz)) events.push({type:'원진', pos:POS[i], weight:-5});
    if (inPairList(SANGHYEONG, nz, lz)) events.push({type:'상형', pos:POS[i], weight:-6});
    if (nz === lz && JAHYEONG.includes(nz)) events.push({type:'자형', pos:POS[i], weight:-4});
  });
  // ---- 지지 N:1 (삼합/방합/삼형) ----
  const natalZ = natalGZ.map(g => g % 12);
  for (const {set, oh} of SAMHAP){
    if (!set.includes(lz)) continue;
    const have = set.filter(z => z !== lz).filter(z => natalZ.includes(z));
    if (have.length === 2)      events.push({type:'삼합국', weight:+12});
    else if (have.length === 1) events.push({type:'반합',   weight:+5});
  }
  for (const {set} of BANGHAP){
    if (!set.includes(lz)) continue;
    if (set.filter(z => z !== lz).every(z => natalZ.includes(z)))
      events.push({type:'방합국', weight:+10});
  }
  for (const set of SAMHYEONG){
    if (!set.includes(lz)) continue;
    const have = set.filter(z => z !== lz).filter(z => natalZ.includes(z));
    if (have.length === 2)      events.push({type:'삼형', weight:-12});
    else if (have.length === 1) events.push({type:'형',   weight:-5});
  }
  return { events, raw: events.reduce((s,e) => s + e.weight, 0) };
}
```

## 8. 최종 실행 코드 — `calcLuckCycles`

요청 시그니처 `calcLuckCycles(pillars, gender, birthTime)` 어댑터:

```js
/**
 * @param {{yearIdx,monthIdx,dayIdx,hourIdx}} pillars  원국 4주 (0..59)
 * @param {0|1} gender  1=남, 0=여
 * @param {Date} birthTime  KST 벽시계를 UTC 필드에 담은 pseudo-Date
 * @returns {{daewoonNumber:number, daewoons:Array, sewoons:Array}}
 */
function calcLuckCycles(pillars, gender, birthTime){
  const forward = isForward(pillars.yearIdx % 10, gender);
  const st  = computeStart(birthTime, forward);      // §4.3 (A)(B)(C)(D) 전부 산출
  const num = st.daewoonNumberKR;                    // UI 기본 = (C)

  const birthYear = birthTime.getUTCFullYear();
  const startYear = st.startSolar.getUTCFullYear();

  const daewoons = [{ index:0, ganji:null,
    startYear: birthYear, endYear: startYear-1,
    startAgeKorean:1, endAgeKorean: startYear-birthYear,
    startAgeWestern:0, endAgeWestern: Math.max(0, num-1),
    note:'교운 전(小運 구간)' }];

  for (let i = 1; i <= 10; i++){
    const idx = ((pillars.monthIdx + (forward ? i : -i)) % 60 + 60) % 60;
    const sy  = startYear + (i-1)*10;
    daewoons.push({ index:i, ganji: gz(idx), ganjiIndex: idx,
      startYear: sy, endYear: sy+9,
      startAgeKorean: sy-birthYear+1, endAgeKorean: sy-birthYear+10,
      startAgeWestern: num+(i-1)*10, endAgeWestern: num+(i-1)*10+9 });
  }

  const sewoons = [];
  for (let y = birthYear; y < birthYear + 100; y++){
    const gi = ((y - 4) % 60 + 60) % 60;
    const dw = daewoons.find(d => y >= d.startYear && y <= d.endYear) || null;
    sewoons.push({ year:y, ganji: gz(gi), ganjiIndex: gi,
      ageKorean: y-birthYear+1, ageWestern: y-birthYear,
      daewoonIndex: dw && dw.index, daewoonGanji: dw && dw.ganji });
  }
  return { daewoonNumber: num, forward, startDetail: st, daewoons, sewoons };
}
```

전체 소스: `luck-cycles.js` (절기·4주·대운·세운·월운·일운·시운), `interactions.js` (합충·점수).

## 11. 남은 의문 / 후속 과제

1. **1954~1961 UTC+8:30 구간**의 절기 시각을 KASI 공식값과 대조하지 못했다. 이 구간 출생자는 30분 차이 → 교운일 2.5일 차이. (C05 축과 연계 검증 필요)
2. **한국 상용 만세력(더큼/플러스만세력/천을귀인)의 대운수 반올림 규칙**을 실제 앱 출력으로 확인하지 못했다(웹 UI 접근 실패). 케이스 C(2000-01-01 12:00 여)를 각 앱에 넣어 1 vs 2 를 확인하면 국내 다수파 규칙이 확정된다.
3. **삼명통회(三命通會) 원문**의 대운수 서술을 1차 사료로 확인하지 못했다(2차 인용만 확보).
4. **파/해/원진 가중치 절대값**은 문헌 근거 없이 설계값이다. 사용자 반응 A/B 로 튜닝 필요.
5. **대운 간지를 원국에 합류시킨 5주 재판정**(dao.ahncjr.com 3자 상호작용론)은 미구현.
6. **소운(小運)** 은 시주 기점 진행 로직만 확보(`XiaoYun.py`). 교운 전 구간을 소운으로 채우는 UI 정책 미정.
7. lunar-javascript `lunar.js` 의 `JIE_QI_IN_USE` 배열 **전체 정의**를 원문에서 뽑아내지 못했다(파일 과대). 節/中氣 교대 배열임은 `getPrevJie`(짝수 인덱스만 조건 투입)로 간접 확인.
