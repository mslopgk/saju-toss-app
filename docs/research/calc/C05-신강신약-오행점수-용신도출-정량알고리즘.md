def wuxing_strength(pillars, day_gan):
    score = {"木": 0.0, "火": 0.0, "土": 0.0, "金": 0.0, "水": 0.0}
    weights = [1.0, 0.5, 0.2]                 # 본기 / 중기 / 여기
    for idx, (gan, zhi) in enumerate(pillars):
        score[GAN_WUXING[gan]] += 1.0         # 천간은 위치 무관 1.0
        mult = 2.0 if idx == 1 else 1.0       # 月支만 ×2 (月令司令)
        for i, g in enumerate(ZHI_CANGGAN[zhi]):
            w = weights[i] if i < len(weights) else 0.2
            score[GAN_WUXING[g]] += round(w * mult, 3)
    dw   = GAN_WUXING[day_gan]
    yin  = next(k for k, v in WUXING_SHENG.items() if v == dw)   # 印

## 3. 得令·得地·得勢 판정 조건식

### 3.1 조사된 조건 정의

| 조건 | 정의 (durumisaju / HeiGe / 일반 유파) | 조건식 |
|---|---|---|
| **득령(得令)** | 월지가 일간을 생조 = 비겁·인성 월 / 旺·相 상태 | `wangsang(月支, 日干오행) ∈ {旺, 相}` |
| **득지(得地)** | 일지가 비겁·인성 **또는** 12운성 長生·冠帶·建祿·帝旺 | `ZHI5[日支] ∈ {日干오행, 印오행}` **OR** `unseong(日干,日支) ∈ {長生,冠帶,建祿,帝旺}` |
| **득세(得勢)** | 일간 제외 사주 전체에서 인성·비겁이 3자 이상 | `count(비겁·인성 글자) ≥ 3` |

⚠️유파차이 — 득세의 카운트 대상:
| 유파 | 카운트 대상 | 임계 |
|---|---|---|
| 안산김씨/전통 한국 | 일간 제외 **7자 전부**(천간3+지지4) | ≥3 |
| durumisaju | **천간 3자만**(년간·월간·시간) | ≥2 |
| 일부 유파 | 천간 3자만 | ≥3 |
| 중국 계열 | 지장간까지 포함 가중합 | 비율 |
| **C05-STD** | **일간 제외 7자(천간3 + 지지4, 지지는 본기 오행 기준)** | **≥3** |

⚠️유파차이 — 득지에서 12운성을 쓸 것인가:
| 방식 | 결과 차이 예 |
|---|---|
| 오행만 (`日支 ∈ 비겁/인성`) | 庚辰일 → 辰=土=印 → 득지 O |
| 12운성만 | 庚辰일 → 養 → 득지 X |
| **OR (C05-STD)** | 득지 O |
실측 T2(`庚辰`일): 오행 기준 O / 12운성 기준 X → **판정 뒤집힘.** OR 결합이 가장 관대하며 안정적.

### 3.2 3조건 → 라벨 매핑 (전통 유파, 참고용)

| 득령 | 득지 | 득세 | 전통 판정 |
|---|---|---|---|
| O | O | O | 極身强 |
| O | O | X | 身强 |
| O | X | O | 身强 |
| X | O | O | 身强 (中和 쪽) |
| O | X | X | 中和 |
| X | O | X | 身弱 |
| X | X | O | 身弱 (中和 쪽) |
| X | X | X | 極身弱 |

**C05-STD에서 3조건은 판정을 직접 결정하지 않는다** — 점수(SI)가 판정하고, 3조건은 **해설 텍스트 생성용 근거**로만 쓴다. 이유: 3조건은 3비트(8상태)라 해상도가 낮고, 위 표 4~7행이 유파마다 뒤집힌다.

### 3.3 통근(通根) 별도 판정 (mingyu `analyzeRoot` 방식 채택)

```
for 각 주(년월일시):
    if ZHI5[지지] == 日干오행:  강근(strongRoot=true), rootScore += 2
    for 지장간 중/여기 h:
        if GAN5[h] == 日干오행: rootScore += 1
hasRoot   = rootScore > 0
strongRoot= 지지 본기 동기 1개 이상
```
`strongRoot == false && hasRoot == false` 는 **종격(從格) 성립의 필수 조건**이다.

### 4.2 ★ 50% 임계값은 구조적으로 틀렸다 (전수 계산 증명)

아군 = **2개 오행**(비겁+인성), 적군 = **3개 오행**(식상+재성+관성).
균등 분포에서 아군비율 기대값은 50%가 아니라 **40%**다.

전수 계산: 정합 사주 조합 = 년주 60 × 월지 12 × 일주 60 × 시지 12 = **518,400** (월간은 오호둔, 시간은 오서둔으로 결정).
C05-STD 점수식으로 아군비율 R 을 전수 계산한 결과:

```

min    = 0.0000      max    = 1.0000
  P1  = 0.0525   P5  = 0.1400   P10 = 0.1925   P15 = 0.2250   P20 = 0.2562
  P25 = 0.2825   P30 = 0.3063   P35 = 0.3312   P40 = 0.3513   P45 = 0.3750

### 4.3 C05-STD 확정 — 백분위 정규화 신강지수 SI

|---|---|---|

| SI ≥ 90 | 극신강 | 10% |

용신 분기용 2치 판정: **`isStrong = (SI >= 55)`**, 억부 중립 밴드 = `45 ≤ SI < 55`.

> 제품 관점 이점: SI는 그대로 0~100 UI 게이지로 쓸 수 있고, "당신은 상위 20%의 신강 사주"라는 문장이 **실제로 참**이 된다.

### 6.1 8격 + 건록/양인 판정 (자평진전 계열, mingyu `baziPatternStrategy.ts` 채택)

```
determineGeokguk(pillars, SI):
  day = 일간; mz = 월지; hidden = HIDDEN[mz]        # [본기, 중기, 여기]
  exposed = [년간, 월간, 시간]                       # ★ 일간은 투출 대상에서 제외

  # ── 0단계: 특수격 선검사 (§6.2)
  if 전왕격조건: return 전왕격
  if 종격조건:   return 종재/종살/종아/종세격

  # ── 1단계: 록/인 위치 고정격
  if LU[day]     == mz: return 건록격
  if YANGIN[day] == mz: return 양인격          # 양간만

  # ── 2단계: 월지 지장간의 투출 검사
  candidates = []
  for j, h in enumerate(hidden):                # j=0 본기, 1 중기, 2 여기
      if tenGod(day,h) in {比肩, 劫財}: continue  # 비겁은 격이 되지 않음
      pos = [p for p in {월간:0, 시간:1, 년간:2} if exposed[p]==h]
      if pos: candidates.append( (j, -len(pos), min(rank), h) )

  # ── 3단계: 정렬 (사전식) → 1) 본기>중기>여기  2) 투출 횟수 多  3) 월간>시간>년간
  if candidates:
      candidates.sort()
      h = candidates[0].h
      return f"{tenGod(day,h)}격"

  # ── 4단계: 투출 없음 → 월지 본기 십신
  g = tenGod(day, hidden[0])
  return {比肩:'건록격', 劫財:'양인격'}.get(g, f"{g}격")
```

## 7. C05-STD v1 — 단일 확정 규칙 (제품 채택안)

### 7.1 점수 모델

```
score[오행] = Σ (천간 기여) + Σ (지장간 기여)

천간 기여 (일간 제외 3자):
    년간 : 10 × 0.8 = 8.0
    월간 : 10 × 1.0 = 10.0
    시간 : 10 × 0.8 = 8.0
    일간 : 0  (주체이므로 점수화하지 않음 — 자기 자신을 세면 항상 아군 편향)

지장간 기여 (4지지 전부):
    base = 10 × 지지가중
      지지가중: 년지 1.0 / 월지 2.0 / 일지 1.4 / 시지 1.0
    분배비율:
      3자 지장간(丑寅辰巳未申戌) : 본기 0.60 / 중기 0.25 / 여기 0.15
      2자 지장간(午亥)           : 본기 0.70 / 중기 0.30
      1자 지장간(子卯酉)          : 본기 1.00

총점 total = 8 + 10 + 8 + 10×(1.0+2.0+1.4+1.0) = 26 + 54 = 80.0  (항상 고정)
```

**총점이 항상 80.00 고정**인 것이 이 모델의 핵심 성질이다 — 비율 계산이 안정적이고 디버깅이 쉽다.

계수 근거:
- 지장간 0.60/0.25/0.15 : HeiGe(1/0.5/0.2 → 0.588/0.294/0.118)와 china-testing(5/2/1 → 0.625/0.250/0.125)과 be-realdeveloper(0.6/0.2/0.2)의 중앙값 근사, 합=1.00 정규화.
- 월지 ×2.0 : HeiGe·china-testing 공통 채택 계수. "월령이 30~50% 비중"이라는 통설과도 정합(월지 20/80 = 25%, 월간 포함시 37.5%).
- 일지 ×1.4 : HeiGe 02 원문 「**坐下(日支)通根力量最重**」의 정량화. 년/시지와 월지 사이 값.
- 년간/시간 0.8 : 자평진전의 「월령 제강」 원칙 반영. 월간만 1.0.
- 일간 0점 : 모델 A·B·D·E가 모두 일간을 점수에 포함시켜 **아군 쪽으로 구조적 편향**을 만든다. STD는 제외.

### 7.2 아군/적군 및 SI

```
ally = score[비겁오행] + score[인성오행]
foe  = score[식상] + score[재성] + score[관성]      # = 80 - ally
R    = ally / 80
SI   = percentileRank(R)   # §4.3 앵커표 선형보간, 0~100
grade= §4.3 7등급표
isStrong = (SI >= 55)

### 7.4 의사코드 — `analyzeStrength(pillars)`

```typescript
type Pillar   = { gan: Gan; zhi: Zhi };
type Pillars  = [Pillar, Pillar, Pillar, Pillar];   // [년, 월, 일, 시]
type Elem     = '木'|'火'|'土'|'金'|'水';

interface StrengthResult {
  scores:  Record<Elem, number>;   // 합 = 80.00
  total:   80;
  ally: number; foe: number; R: number;
  SI: number;                      // 0~100 신강지수
  grade: '극신약'|'신약'|'중화신약'|'중화'|'중화신강'|'신강'|'극신강';
  isStrong: boolean;               // SI >= 55
  deuk: { deukryeong: boolean; wangsang: '旺'|'相'|'休'|'囚'|'死';
          deukji: boolean; unseongIlji: string;
          deukse: boolean; allyCount: number; condCount: 0|1|2|3 };
  root: { hasRoot: boolean; strongRoot: boolean; rootScore: number; roots: string[] };
  gyeokguk: { name: string; special: boolean; basis: string };
  yongsin: { primary: Elem; favorable: Elem[]; avoid: Elem[];
             route: '從/專旺'|'調候'|'抑扶+格局'|'通關';
             climateIndex: number; tiaohouChars: string; steps: string[] };
}

const POS_GAN_W    = { year:0.8, month:1.0, day:0.0, hour:0.8 };  // 일간 0
const POS_ZHI_W    = { year:1.0, month:2.0, day:1.4, hour:1.0 };
const HIDDEN_RATIO = { 3:[0.60,0.25,0.15], 2:[0.70,0.30], 1:[1.00] };

function analyzeStrength(p: Pillars): StrengthResult {
  const day = p[2].gan, dw = GAN5[day];
  const P = { bi: dw, ins: INV_SHENG[dw], sik: SHENG[dw],
              jae: KE[dw], gwan: INV_KE[dw] };

  // ── STEP 1. 오행 점수 (총 80.00)
  const scores = { 木:0, 火:0, 土:0, 金:0, 水:0 };
  for (const [i, pos] of ['year','month','day','hour'].entries()) {
    scores[GAN5[p[i].gan]] += 10 * POS_GAN_W[pos];
    const hs = HIDDEN[p[i].zhi], ratio = HIDDEN_RATIO[hs.length];
    hs.forEach((h, j) => { scores[GAN5[h]] += 10 * POS_ZHI_W[pos] * ratio[j]; });
  }

  // ── STEP 2. 아군비율 → SI → 등급
  const ally = scores[P.bi] + scores[P.ins];
  const R = ally / 80;
  const SI = percentileRank(R);                 // §4.3 앵커 선형보간
  const grade = gradeOf(SI);
  const isStrong = SI >= 55;

  // ── STEP 3. 득령·득지·득세 (해설용 근거)
  const ws = WANGSANG[p[1].zhi][dw];
  const deukryeong = ws === '旺' || ws === '相';
  const us = unseong(day, p[2].zhi);
  const deukji = [dw, P.ins].includes(ZHI5[p[2].zhi])
              || ['長生','冠帶','建祿','帝旺'].includes(us);
  let allyCount = 0;
  p.forEach((q, i) => {
    if (i !== 2 && [dw, P.ins].includes(GAN5[q.gan])) allyCount++;
    if ([dw, P.ins].includes(ZHI5[q.zhi]))            allyCount++;
  });
  const deukse = allyCount >= 3;

  // ── STEP 4. 통근
  let rootScore = 0, strongRoot = false;
  p.forEach(q => {
    const main = ZHI5[q.zhi] === dw;
    if (main) { strongRoot = true; rootScore += 2; }
    HIDDEN[q.zhi].forEach((h, j) => {
      if (main && j === 0) return;
      if (GAN5[h] === dw) rootScore += 1;
    });
  });
  const hasRoot = rootScore > 0;

  // ── STEP 5. 격국 (§6.1)
  const gyeokguk = determineGeokguk(p, SI, hasRoot);

  // ── STEP 6. 용신 5관 (§5.1)
  const yongsin = selectYongsin(p, SI, gyeokguk, scores, P);

  return { scores, total: 80, ally, foe: 80 - ally, R, SI, grade, isStrong,
           deuk: { deukryeong, wangsang: ws, deukji, unseongIlji: us,
                   deukse, allyCount,
                   condCount: +deukryeong + +deukji + +deukse },
           root: { hasRoot, strongRoot, rootScore, roots },
           gyeokguk, yongsin };
}

function selectYongsin(p, SI, gg, scores, P): Yongsin {
  const dw = GAN5[p[2].gan];
  const ci = climateIndex(p);                    // §5.3
  const th = TIAOHOU[p[2].gan][p[1].zhi];        // §5.4 표 ①
  const steps: string[] = [];

  // 1관 — 종격/전왕 (최고 거부권)
  if (gg.special) {
    if (gg.name === '전왕격')
      return { primary: dw, favorable: [dw, INV_SHENG[dw], SHENG[dw]],
               avoid: [KE[dw], INV_KE[dw]], route: '從/專旺', ... };
    return { primary: SHENG[dw], favorable: [SHENG[dw], KE[dw], INV_KE[dw]],
             avoid: [dw, INV_SHENG[dw]], route: '從/專旺', ... };
  }

  // 2관 — 조후 급증
  const urgent = ci <= -12 ? '火' : ci >= 12 ? '水' : null;
  if (urgent && scores[urgent] < 8.0)
    return { primary: urgent, favorable: [urgent, INV_SHENG[urgent]],
             avoid: [INV_KE[urgent]], route: '調候', ... };

  // 3관 — 억부 (방향)
  let order: Elem[], avoid: Elem[];
  if (SI >= 55)      { order = [P.gwan, P.sik, P.jae]; avoid = [P.ins, P.bi]; }
  else if (SI < 45)  { order = [P.ins, P.bi];          avoid = [P.gwan, P.jae]; }
  else               { order = [GAN5[th[0]]];          avoid = []; }   // 중립밴드

  // 4관 — 격국 (정밀화): 격국 십신오행이 억부 방향 안에 있으면 1순위 승격
  const ge = GOD_ELEM[gg.name.replace('격','')];
  if (ge && order.includes(ge)) order = [ge, ...order.filter(x => x !== ge)];

  // 5관 — 병약: 용신을 극하는 오행 K가 총점 20% 이상이면 藥(=INV_KE[K])을 희신에 추가
  const K = INV_KE[order[0]];
  if (scores[K] >= 16.0) order.push(INV_KE[K]);

  return { primary: order[0], favorable: order, avoid,
           route: '抑扶+格局', climateIndex: ci, tiaohouChars: th, steps };
}
```

- 득령: 巳월 木 → 休 → **X**  ／ 득지: 巳는 火 ✗, 12운성 乙-巳 = 沐浴 ✗ → **X** ／ 득세: 월간癸(水) 1자 → **X** (조건 0/3)
- 통근: 지지 본기(火,火,火,土) 중 木 없음. 지장간 중여기에도 乙/甲 없음 → **hasRoot = false**
- 격국: `SI ≤ 8` **AND** `hasRoot == false` → **종격 성립**. 세분: 이당 카테고리 = {식상(火), 재성(土), 관성(金)} 3종 혼잡 → **종세격**
- 용신(1관에서 확정): 종격 → 順勢 → `[식상 火, 재성 土, 관성 金]`, 기신 `[木, 水]`
- **용신 = 火, 희신 土·金, 기신 木·水**
