⚠️**유파차이 — Tropical vs Sidereal**
위 표는 **Tropical(회귀) 황도대** 기준(λ=0°가 춘분점). 서양 점성술 99%가 이것이다.
Vedic/Jyotish는 **Sidereal(항성) 황도대** = `λ_sidereal = λ_tropical - ayanamsa`.
- Lahiri ayanamsa(2000.0) ≈ 23.85°, 2026년 ≈ 24.20° (연 ~50.29″ 증가)

- **선택**: 토스 미니앱은 대중이 아는 "별자리"를 기대하므로 **Tropical 고정**.

## 1. 시각·좌표 기반 상수

### 1.1 율리우스일 (Meeus Ch.7, 그레고리력)

```js
function julianDay(y, m, d, utHours){
  if (m <= 2){ y -= 1; m += 12; }
  const A = Math.floor(y/100), B = 2 - A + Math.floor(A/4);
  return Math.floor(365.25*(y+4716)) + Math.floor(30.6001*(m+1))
       + d + B - 1524.5 + utHours/24;
}
// 검증: julianDay(2000,1,1,12) = 2451545.000000  (J2000.0 정의값과 일치)
// 검증: julianDay(1990,5,15,4.5) = 2448026.687500
```

### 1.3 황도경사 ε (Meeus 22.2 / Laskar 다항식)

```js
function meanObliquity(jd){
  const U = (jd - 2451545.0)/3652500.0;   // 10000 율리우스년 단위
  const c = [84381.448, -4680.93, -1.55, 1999.25, -51.38, -249.67,
             -39.05, 7.12, 27.87, 5.79, 2.45];   // 단위: 각초
  let s = 0;
  for (let i = c.length-1; i >= 1; i--) s = (s + c[i]) * U;
  return (c[0] + s) / 3600.0;   // 도
}
// ε_true = ε_mean + Δε
```

장동(nutation, Meeus 22.2 저정밀 — 정확도 0.5″):

```js
function nutation(jd){
  const T  = (jd-2451545)/36525;
  const Om = 125.04452 - 1934.136261*T;     // 달 승교점 평균황경
  const L  = 280.4665  + 36000.7698*T;      // 태양 평균황경
  const Lp = 218.3165  + 481267.8813*T;     // 달  평균황경
  const dpsi = (-17.20*sind(Om) - 1.32*sind(2*L) - 0.23*sind(2*Lp) + 0.21*sind(2*Om))/3600;
  const deps = (  9.20*cosd(Om) + 0.57*cosd(2*L) + 0.10*cosd(2*Lp) - 0.09*cosd(2*Om))/3600;
  return {dpsi, deps};
}
```

### 2.4 입궁 시각 탐색 (이분법)

```js
function findIngress(year, targetLon, monthGuess){
  let lo = new Date(Date.UTC(year, monthGuess-1, 1));
  let hi = new Date(Date.UTC(year, monthGuess+1, 1));
  const f = dt => { let x = A.SunPosition(dt).elon - targetLon;
                    while (x > 180) x -= 360; while (x < -180) x += 360; return x; };
  for (let i=0;i<80;i++){
    const mid = new Date((lo.getTime()+hi.getTime())/2);
    if (f(lo)*f(mid) <= 0) hi = mid; else lo = mid;
  }
  return new Date((lo.getTime()+hi.getTime())/2);
}
```
80회 이분법 → 구간 폭 `61일 / 2^80` ≈ 나노초 이하. 실제로는 40회면 밀리초 수렴.
**권장**: 앱은 이 함수로 사용자 생년의 12개 입궁 시각을 계산해 캐싱(연간 12개 = 아주 작음).

### 4.2 ASC 공식 (형태 1 — 문제문 지정형, atan2 사분면 보정)

```
                    cos(RAMC)
tan(ASC) = ─────────────────────────────────────
           −( sin(RAMC)·cos(ε) + tan(φ)·sin(ε) )
```

**단순 `atan`을 쓰면 반드시 사분면 보정이 필요하다.** `atan2`를 쓰면 보정이 자동:

```js
function ascendant(RAMC, eps, lat){
  const y = cosd(RAMC);
  const x = -(sind(RAMC)*cosd(eps) + tand(lat)*sind(eps));
  return mod360(Math.atan2(y, x) * 180/Math.PI);   // 사분면 자동 처리
}
```

`atan` 버전을 쓸 경우의 명시적 보정 규칙 (Duffett-Smith / Wikipedia Ascendant):
```
ASC = atan( cos(RAMC) / −(sin(RAMC)cos ε + tan φ sin ε) )   [도, −90..+90]
if (denominator < 0) ASC += 180;  else ASC += 360;
if (ASC >= 180) ASC -= 180;  else ASC += 180;
ASC = ASC mod 360;
```
(이 보정 시퀀스는 CircularNatalHoroscopeJS `src/utilities/astronomy.js` 의 `getAscendant`와 동일 —
실제 소스 발췌는 §7.1)

### 4.3 ASC 공식 (형태 2 — Swiss Ephemeris `Asc1`/`Asc2`, 하우스와 통합)

Swiss Ephemeris `swehouse.c` 는 ASC를 **극고(pole height) f 를 가진 대원과 황도의 교점**이라는
일반화된 함수로 푼다. ASC는 `f = φ (지리위도)`, `x = RAMC + 90` 인 특수 케이스다.
Placidus 하우스가 같은 함수를 재사용하므로 **이 형태를 채택하는 편이 코드가 준다.**

```js
// swehouse.c Asc2() 그대로 포팅 — 구면삼각법 CT5: cot c·sin a = cot C·sin B + cos a·cos B
function Asc2(x, f, sine, cose){
  let ass = -tand(f)*sine + cose*cosd(x);
  if (Math.abs(ass) < VERY_SMALL) ass = 0;
  let sinx = sind(x); if (Math.abs(sinx) < VERY_SMALL) sinx = 0;
  if (sinx === 0)      ass = ass < 0 ? -VERY_SMALL : VERY_SMALL;
  else if (ass === 0)  ass = sinx < 0 ? -90 : 90;
  else                 ass = atand(sinx / ass);
  if (ass < 0) ass = 180 + ass;
  return ass;
}
// swehouse.c Asc1() — 사분면 분기가 여기 들어있다
function Asc1(x1, f, sine, cose){
  x1 = mod360(x1);
  const n = Math.floor(x1/90) + 1;              // 사분면 1..4
  if (Math.abs(90 - f) < VERY_SMALL) return 180; // 북극
  if (Math.abs(90 + f) < VERY_SMALL) return 0;   // 남극
  let ass;
  if      (n === 1) ass =       Asc2(x1,       f, sine, cose);
  else if (n === 2) ass = 180 - Asc2(180 - x1, -f, sine, cose);
  else if (n === 3) ass = 180 + Asc2(x1 - 180, -f, sine, cose);
  else              ass = 360 - Asc2(360 - x1,  f, sine, cose);
  return mod360(ass);
}
// ASC:
const asc = Asc1(RAMC + 90, latitude, sind(eps), cosd(eps));
```

## 5. 하우스 시스템

### 5.1 Whole Sign (전체 별자리) — 가장 단순, 실패 없음

```js
function wholeSign(asc){
  const s = Math.floor(mod360(asc)/30);
  const cusp = new Array(13);
  for (let i=1;i<=12;i++) cusp[i] = mod360((s + i - 1)*30);
  return cusp;
}
```
- 1하우스 = ASC가 속한 궁 **전체**. 커스프는 항상 0°, 30°, 60°, ….
- **모든 위도에서 항상 정의됨.** 극지에서도 실패 없음.
- 구현 난이도 **★☆☆☆☆** (3줄)
- Swiss Ephemeris에서 hsys='W': `cusp[1] = ac - fmod(ac, 30)`

### 5.2 Equal House (등분) — ASC부터 30°씩

```js
function equalHouse(asc){
  const cusp = new Array(13);
  for (let i=1;i<=12;i++) cusp[i] = mod360(asc + (i-1)*30);
  return cusp;
}
```
- 1하우스 커스프 = ASC **정확히**. 이후 30°씩.
- MC가 10하우스 커스프와 일치하지 않는다 (Placidus와의 핵심 차이).
- 구현 난이도 **★☆☆☆☆**
- 극권 예외(swehouse.c hsys='A'/'E'): `if (difdeg2n(ac, mc) < 0) ac += 180` — AC/DC 스왑

### 5.3 Placidus — 시간 삼등분, **반복 수렴 필요, 극권에서 정의 불가**

원리: 황도상의 각 점은 지평선 위로 뜨는 데 걸리는 시간(주간 반호 SA)이 있다.
Placidus는 이 **시간**을 3등분한다. 해석적 해가 없어 **반복법** 필수.

**Swiss Ephemeris `swehouse.c` (default: Placidus) 원문 알고리즘의 충실한 포팅:**

```js
function placidus(th /*RAMC*/, fi /*위도*/, ekl /*ε*/){
  const sine=sind(ekl), cose=cosd(ekl), tane=tand(ekl), tanfi=tand(fi);

  // ★ 극권 실패 조건 — swehouse.c 원문 그대로
  if (Math.abs(fi) >= 90 - ekl) return null;   // "within polar circle, switched to Porphyry"

  const a   = asind(tanfi * tane);
  const fh1 = atand(sind(a/3)     / tane);
  const fh2 = atand(sind(a*2/3)   / tane);

  const cusp = new Array(13);
  cusp[10] = mod360(Math.atan2(sind(th), cosd(th)*cose) * R2D);   // MC
  cusp[1]  = Asc1(th + 90, fi, sine, cose);                        // ASC

  // [하우스번호, RA 오프셋, 분모] — 11:30°/3, 12:60°/1.5, 2:120°/1.5, 3:150°/3
  for (const [ih, off, div] of [[11,30,3],[12,60,1.5],[2,120,1.5],[3,150,3]]){
    const rectasc = mod360(off + th);
    const fh = (div === 3) ? fh1 : fh2;
    let tant = tand(asind(sine * sind(Asc1(rectasc, fh, sine, cose))));
    if (Math.abs(tant) < VERY_SMALL){ cusp[ih] = rectasc; continue; }
    let f = atand(sind(asind(tanfi*tant)/div) / tant);   // pole height
    cusp[ih] = Asc1(rectasc, f, sine, cose);
    let cuspsv = 0, i;
    for (i = 1; i <= 100; i++){                            // niter_max = 100
      tant = tand(asind(sine * sind(cusp[ih])));
      if (Math.abs(tant) < VERY_SMALL){ cusp[ih] = rectasc; break; }
      f = atand(sind(asind(tanfi*tant)/div) / tant);
      cusp[ih] = Asc1(rectasc, f, sine, cose);
      if (i > 1 && Math.abs(difdeg2n(cusp[ih], cuspsv)) < 1e-10) break;
      cuspsv = cusp[ih];
    }
    if (i >= 100) return null;   // "very close to polar circle, switched to Porphyry"
  }
  // 대척점
  cusp[4]=mod360(cusp[10]+180); cusp[5]=mod360(cusp[11]+180); cusp[6]=mod360(cusp[12]+180);
  cusp[7]=mod360(cusp[1]+180);  cusp[8]=mod360(cusp[2]+180);  cusp[9]=mod360(cusp[3]+180);
  return cusp;
}
```

**수렴 반복 횟수 실측:**

| 케이스 | 위도 | `a=asin(tanφ·tanε)` | fh1 | fh2 | 반복수 {c2,c3,c11,c12} |
|---|---:|---:|---:|---:|---|
| TV-1 서울 | 37.5665° | 19.482761° | 14.619283° | 27.399167° | {2, 3, 3, 4} |
| TV-3 부산 | 35.1796° | 17.793870° | 13.406677° | 25.368504° | {3, 3, 3, 3} |
| TV-4 뉴욕 | 40.7128° | 21.909772° | 16.338919° | 30.180539° | {4, 3, 4, 4} |
| TV-5 레이캬비크 | 64.1466° | 63.488166° | 39.780121° | 57.219581° | {3, 5, 8, 7} |
| TV-6 트롬쇠 | 69.6492° | — | — | — | **실패 (극권)** |

→ 저위도는 **2~4회**, 고위도(64°)는 **8회**까지 필요. 100회 상한 내 항상 수렴하거나 극권 조건에서 조기 실패.

**★ 극권 실패 조건 정확히:** `|φ| ≥ 90° − ε`
ε ≈ 23.44° → **|φ| ≥ 66.56°** 에서 Placidus는 **수학적으로 정의 불가**.
황도의 일부 도수가 주극성(circumpolar)이 되어 절대 뜨거나 지지 않으므로 주간 반호가 없다.

**Fallback (Swiss Ephemeris 표준): Porphyry**
```js
function porphyry(asc, mc){
  let acmc = difdeg2n(asc, mc);
  if (acmc < 0){ asc = mod360(asc+180); acmc = difdeg2n(asc, mc); }
  const c = new Array(13);
  c[1]=asc; c[10]=mc; c[4]=mod360(mc+180); c[7]=mod360(asc+180);
  c[2] = mod360(asc + (180-acmc)/3);   c[3] = mod360(asc + (180-acmc)/3*2);
  c[11]= mod360(c[4] + acmc/3);        c[12]= mod360(c[4] + acmc/3*2);
  c[5]=mod360(c[11]+180); c[6]=mod360(c[12]+180);
  c[8]=mod360(c[2]+180);  c[9]=mod360(c[3]+180);
  return c;
}
```

```js
export const getLocalSiderealTime = ({ jd = 0, longitude = 0 } = {}) => {
  // Source: Astronomical Algorithims by Jean Meeus (1991) - Ch 11, pg 84 formula 11.4
  const julianDaysJan1st2000 = 2451545.0;
  const julianDaysSince2000 = jd - julianDaysJan1st2000;
  const tFactor = (julianDaysSince2000) / 36525; // centuries
  const degreesRotationInSiderealDay = 360.98564736629;
  const lst = 280.46061837
    + (degreesRotationInSiderealDay * (julianDaysSince2000))
    + 0.000387933 * Math.pow(tFactor, 2)
    - (Math.pow(tFactor, 3) / 38710000)
    + longitude;
  return modulo(parseFloat(lst), 360);
};

export const getAscendant = ({ latitude = 0.00, obliquityEcliptic = 23.4367,
                               localSiderealTime = 0.00 } = {}) => {
  const a = -cosFromDegrees(localSiderealTime);
  const b = sinFromDegrees(obliquityEcliptic) * tanFromDegrees(latitude);
  const c = cosFromDegrees(obliquityEcliptic) * sinFromDegrees(localSiderealTime);
  const d = b + c;
  const e = a / d;
  const f = Math.atan(e);
  let ascendant = radiansToDegrees(f);
  // citation Peter Duffett-Smith, Jonathan Zwart,
  // Practical astronomy with your calculator or spreadsheet-4th ed., p47, 2011
  if (d < 0) { ascendant += 180; } else { ascendant += 360; }
  if (ascendant >= 180) { ascendant -= 180; } else { ascendant += 180; }
  return modulo(ascendant, 360);
};
```

**⚠️ 이 구현의 결함 2가지 (본 문서 구현에서 수정함):**
1. `obliquityEcliptic = 23.4367` **하드코딩 기본값** — 소스 주석에 "for Mean Obliquity on
   Sept. 22 2019 at 0000 UTC" 라고 명시. `getObliquityEcliptic()`은 **빈 함수**(`=> {}`)로 미구현.
   1930년생에게 쓰면 ε 오차 ~0.0014° → ASC 오차 수 각초. 실무 영향은 작으나 정확하지 않음.
2. `getLocalSiderealTime`이 **GMST(평균)** 를 계산하는데 결과를 RAMC(겉보기)로 쓴다.
   `Δψ·cos ε` (분점방정식, 최대 ±1.1″) 만큼 편향.

### 7.1 계산 공식

```js
// 두 천체 황경차 → 0..180 범위 각거리
function separation(lon1, lon2){
  let d = ((lon1 - lon2) % 360 + 360) % 360;
  return d > 180 ? 360 - d : d;
}
// 어스펙트 판정
function findAspects(lonA, lonB, orbMax){
  const sep = separation(lonA, lonB);
  const out = [];
  for (const {name, angle} of ASPECTS){
    const dev = Math.abs(sep - angle);          // orb (실제 이탈각)
    if (dev <= orbMax) out.push({name, sep, orb: dev,
                                 strength: 1 - dev/orbMax});   // 0..1 정규화 강도
  }
  return out;
}
```

- 방식 A(고정 orb) 적용: 어스펙트 **25개** 검출 (Sun-Pluto Opposition sep=172.082° orb=7.918°/10° 포함)

**⚠️유파차이 — Applying vs Separating**
어스펙트가 정확각에 **가까워지는 중(applying)** 인지 **멀어지는 중(separating)** 인지 구분하는 유파가 있다.
판정: 빠른 천체가 느린 천체를 향해 접근 중이면 applying. 구현하려면 각 천체의 일주 운동량(°/day)이 필요.
```js
const speedA = (lon(t + 1h) - lon(t - 1h)) / (2/24);   // °/day, 수치미분
const applying = Math.sign(sep(t+ε) - sep(t)) < 0;
```
Applying 어스펙트에 가중치를 더 주는 것이 일반적이나, **미적용해도 무방**(대중 앱 수준).

## 8. 권장 구현 — 실행 가능 코드 (실측 검증 완료)

`npm install astronomy-engine` (MIT, 1.8 MB) 만으로 완결.

```js
const A = require('astronomy-engine');
const D2R = Math.PI/180, R2D = 180/Math.PI, VS = 1e-10;
const mod360 = x => ((x % 360) + 360) % 360;
const sind=d=>Math.sin(d*D2R), cosd=d=>Math.cos(d*D2R), tand=d=>Math.tan(d*D2R);
const asind=x=>Math.asin(x)*R2D, atand=x=>Math.atan(x)*R2D;
const d2n=(a,b)=>{ let d=mod360(a-b); return d>180 ? d-360 : d; };

const SIGNS_KO = ['양자리','황소자리','쌍둥이자리','게자리','사자자리','처녀자리',
                  '천칭자리','전갈자리','사수자리','염소자리','물병자리','물고기자리'];
const signIndex = lon => Math.floor(mod360(lon)/30);

function julianDay(y,m,d,ut){ if(m<=2){y-=1;m+=12;}
  const a=Math.floor(y/100), b=2-a+Math.floor(a/4);
  return Math.floor(365.25*(y+4716))+Math.floor(30.6001*(m+1))+d+b-1524.5+ut/24; }

function meanObliquity(jd){ const U=(jd-2451545)/3652500;
  const c=[84381.448,-4680.93,-1.55,1999.25,-51.38,-249.67,-39.05,7.12,27.87,5.79,2.45];
  let s=0; for(let i=c.length-1;i>=1;i--) s=(s+c[i])*U; return (c[0]+s)/3600; }

function nutation(jd){ const T=(jd-2451545)/36525;
  const O=125.04452-1934.136261*T, L=280.4665+36000.7698*T, Lp=218.3165+481267.8813*T;
  return { dpsi:(-17.20*sind(O)-1.32*sind(2*L)-0.23*sind(2*Lp)+0.21*sind(2*O))/3600,
           deps:(  9.20*cosd(O)+0.57*cosd(2*L)+0.10*cosd(2*Lp)-0.09*cosd(2*O))/3600 }; }

// --- Swiss Ephemeris Asc1/Asc2 포팅 (ASC + Placidus 공용) ---
function Asc2(x,f,se,ce){
  let a = -tand(f)*se + ce*cosd(x); if (Math.abs(a)<VS) a=0;
  let sx = sind(x); if (Math.abs(sx)<VS) sx=0;
  if (sx===0) a = a<0?-VS:VS; else if (a===0) a = sx<0?-90:90; else a = atand(sx/a);
  return a<0 ? 180+a : a;
}
function Asc1(x,f,se,ce){
  x = mod360(x); const n = Math.floor(x/90)+1;
  if (Math.abs(90-f)<VS) return 180;
  if (Math.abs(90+f)<VS) return 0;
  let a;
  if      (n===1) a =       Asc2(x,       f, se, ce);
  else if (n===2) a = 180 - Asc2(180-x,  -f, se, ce);
  else if (n===3) a = 180 + Asc2(x-180,  -f, se, ce);
  else            a = 360 - Asc2(360-x,   f, se, ce);
  return mod360(a);
}

/**
 * @param {number} tzOffsetHours  한국=9, 뉴욕 EDT=-4
 * @param {number} lat  북위 +
 * @param {number} lon  동경 +
 */
function computeChart({year, month, day, hour, minute, tzOffsetHours, lat, lon}){
  const hLocal = hour + minute/60;
  const dt  = new Date(Date.UTC(year, month-1, day) - tzOffsetHours*3600000 + hLocal*3600000);
  const utH = (dt.getTime() - Date.UTC(year, month-1, day)) / 3600000;
  const jd  = julianDay(year, month, day, utH);
  const nut = nutation(jd);
  const eps = meanObliquity(jd) + nut.deps;             // 진황도경사
  const ramc = mod360(A.SiderealTime(dt)*15 + lon);     // GAST(h)*15 + 경도

  const sunLon  = A.SunPosition(dt).elon;               // 겉보기 진황경
  const moon    = A.EclipticGeoMoon(dt);
  const asc = Asc1(ramc + 90, lat, sind(eps), cosd(eps));
  const mc  = mod360(Math.atan2(sind(ramc), cosd(ramc)*cosd(eps)) * R2D);

  // Whole Sign 하우스 (실패 없음)
  const houses = [];
  for (let i=0;i<12;i++) houses.push(mod360((signIndex(asc)+i)*30));

  return {
    jd, eps, ramc,
    sun:  { lon: sunLon,   sign: signIndex(sunLon),   name: SIGNS_KO[signIndex(sunLon)] },
    moon: { lon: moon.lon, lat: moon.lat,
            sign: signIndex(moon.lon), name: SIGNS_KO[signIndex(moon.lon)] },
    asc:  { lon: asc, sign: signIndex(asc), name: SIGNS_KO[signIndex(asc)] },
    mc:   { lon: mc,  sign: signIndex(mc),  name: SIGNS_KO[signIndex(mc)] },
    houses
  };
}
```
