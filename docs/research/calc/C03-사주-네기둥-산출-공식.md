## 0. 전체 파이프라인 (결정적 순서)

```
(1) 입력   : 생년월일시(벽시계) + 표준시 오프셋 + 서머타임 여부 + 출생지 경도
(2) 절대시각: utcMillis = Date.UTC(y,mo-1,d,h,mi) − (stdOffsetMin + dstMin)·60000
(3) 진태양시: tstMillis = utcMillis + (경도° × 4분 + 균시차(분)) × 60000
(4) 월지    : 절대시각을 12절(節) 절입시각 구간에 매핑  → monthOrder ∈ [0..11] (0=寅)
(5) 연간지  : 입춘 절입 기준 보정연도 yearForSaju → (Y−4) mod 10 / mod 12
(6) 월간    : 오호둔(五虎遁)  monthGan = (OHODUN[yearGan] + monthOrder) mod 10
(7) 일간지  : dayIdx60 = (JDN_정오(진태양시 날짜) − 11) mod 60
(8) 시지    : 진태양시 시:분 → 12시진 경계표
(9) 시간    : 오서둔(五鼠遁)  hourGan = ((dayGan mod 5)×2 + hourZhi) mod 10
```

핵심 상수는 딱 4개다: **−11**(일주 JDN 오프셋), **−4**(연주 오프셋), **OHODUN=(2g+2) mod 10**, **OSEODUN=(g mod 5)×2**.

### 1.3 (간,지) → 60갑자 index 역변환

간·지의 홀짝이 같아야만 존재하는 조합이다. 중국인의 나머지 정리 해:

```
n ≡ g (mod 10),  n ≡ z (mod 12)   ⇒   n = (6g − 5z) mod 60
```

검증: (0,0)→0 甲子, (4,6)→24−30=−6→**54** 戊午, (9,11)→54−55=−1→**59** 癸亥. 60개 전부 왕복 일치 확인(테스트 [A]).

## 3. 연주(年柱) — 입춘 절입 시각 기준

### 3.1 공식과 유도

간지 기년은 **서기 4년 = 甲子년**을 기점으로 한다. 따라서 0-base 인덱스는

```
yearGanIdx = (Y − 4) mod 10
yearZhiIdx = (Y − 4) mod 12
```

여기서 `Y`는 **입춘 보정연도(yearForSaju)** 이지 달력 연도가 아니다.

유도 검증(1-base로 표기하는 중국 자료는 `(Y−3) mod 10`을 쓴다 — 동일식의 1-base 표현):

| Y | (Y−4) mod 10 | (Y−4) mod 12 | 간지 | 실제 |
|---|---|---|---|---|
| 1984 | 0 甲 | 0 子 | 甲子 | 甲子 ✓ |
| 2000 | 6 庚 | 4 辰 | 庚辰 | 庚辰 ✓ |
| 2024 | 0 甲 | 4 辰 | 甲辰 | 甲辰 ✓ |
| 2025 | 1 乙 | 5 巳 | 乙巳 | 乙巳 ✓ |
| 2026 | 2 丙 | 6 午 | 丙午 | 丙午 ✓ |

`lunar-javascript`의 `_computeYear` 역시 `var offset = year - 4;` 로 동일하다.

### 3.2 입춘 경계 분기 코드

**연주가 바뀌는 순간은 1월 1일도 동지도 아니고 입춘 절입시각(태양황경 315°)이다.**

```ts
// 절대시각(UTC ms) 기준 비교. 벽시계 문자열 비교 금지.
function yearForSaju(birthUtcMillis: number, gYear: number): number {
  const lichun = solveTerm(315, Date.UTC(gYear, 0, 1) + 34 * 86400000); // 해당 연 입춘 UTC ms
  return birthUtcMillis < lichun ? gYear - 1 : gYear;
}
```

실제 구현에서는 12절 절입시각 목록을 만들어 놓고 "직전 절"을 찾는 방식이 안전하다(월주와 로직 공유).
`monthOrder === 11`(小寒 구간, 1월 초)이면 그 절이 속한 그레고리 연도 `gy`에서 **1을 뺀 값**이 사주년이다.

```ts
const yearForSaju = (monthOrder === 11) ? jeolGregYear - 1 : jeolGregYear;
```

**경계 케이스 실행 결과**

| 입력(KST) | 입춘 2025-02-03 23:10 대비 | 연주 | 월주 |
|---|---|---|---|
| 2025-02-03 23:05 | 5분 전 | **甲辰** | 丁丑(소한) |
| 2025-02-04 00:05 | 55분 후 | **乙巳** | 戊寅(입춘) |

같은 밤 1시간 차이로 연주·월주가 모두 바뀐다.

### 4.2 월간 — 오호둔(五虎遁) 5행 전체

년상기월법(年上起月法). 연간 5그룹 × 寅월 시작 천간:

| 연간 그룹 | 연간 idx | 寅월 천간 | 천간 idx | 결(訣) |
|---|---|---|---|---|
| 甲·己 | 0, 5 | 丙 | 2 | 甲己之年丙作首 |
| 乙·庚 | 1, 6 | 戊 | 4 | 乙庚之歲戊爲頭 |
| 丙·辛 | 2, 7 | 庚 | 6 | 丙辛必定尋庚起 |
| 丁·壬 | 3, 8 | 壬 | 8 | 丁壬壬位順行流 |
| 戊·癸 | 4, 9 | 甲 | 0 | 戊癸何方發，甲寅之上好追求 |

**일반식** (실행 검증 [C]에서 10행 전부 일치):

```
OHODUN[g] = (g * 2 + 2) mod 10
monthGanIdx = (OHODUN[yearGanIdx] + monthOrder) mod 10        // monthOrder: 0=寅
```

`ssaju/src/constants.ts` 의 룩업 테이블과 완전 일치:

```ts
export const YEAR_STEM_TO_MONTH_START_STEM_INDEX: Record<number, number> = {
  0: 2, 1: 4, 2: 6, 3: 8, 4: 0, 5: 2, 6: 4, 7: 6, 8: 8, 9: 0,
};
```

`lunar-javascript`도 동일:

```js
var offset = (((o.yearGanIndexByLiChun + (index<0?1:0)) % 5 + 1) * 2) % 10;
// ((g%5)+1)*2 % 10  ≡  (2g+2) mod 10
```

## 5. 일주(日柱) — JDN 기반, offset = **11** 확정

### 5.1 공식

```ts
// Fliegel–Van Flandern (그레고리력 전용, 정수 JDN = 그날 정오의 JD)
function jdnNoon(y, m, d) {
  const a = Math.floor((14 - m) / 12);
  const yy = y + 4800 - a;
  const mm = m + 12 * a - 3;
  return d + Math.floor((153*mm + 2)/5) + 365*yy
           + Math.floor(yy/4) - Math.floor(yy/100) + Math.floor(yy/400) - 32045;
}

const idx60  = ((jdnNoon(y,m,d) - 11) % 60 + 60) % 60;   // 0 = 甲子
const dayGan = idx60 % 10;
const dayZhi = idx60 % 12;
```

### 5.2 offset 11의 다중 출처 교차검증

| 출처 | 표현 | 0-base 환산 |
|---|---|---|
| `lunar-javascript` `_computeDay` | `var offset = Math.floor(noon.getJulianDay()) - 11; dayGanIndex = offset%10; dayZhiIndex = offset%12;` | **−11** |
| ytliu0 ChineseCalendar 干支 공식(1) | `日干支數 S = 1 + mod(JD正午 − 11, 60)` | **−11** |
| ytliu0 공식(3) | `T = 1 + mod(JD正午 − 1, 10)`, `B = 1 + mod(JD正午 + 1, 12)` | −11 과 동치 |
| `ssaju/src/manse.ts` `getDayPillar` | `baseDate = 1992-10-24, baseGanjiNum = 9 (癸酉)` | **−11 과 동치** |

`(JDN − offset) mod 60 = 54` (2000-01-01 = 戊午) 를 만족하는 offset은 mod 60에서 **11 뿐**이다(전수 탐색, `verify_offset.py`).

### 5.4 자정 경계 처리

- JDN은 **정오 기준 정수**이므로, "그날의 달력 날짜" 하나만 넘기면 시각과 무관하게 그날의 일진이 나온다.
- 일진이 바뀌는 순간은 **진태양시 00:00** (기본 규칙). 23:00~23:59 처리는 §7 참조.
- 그레고리력 이전(1582-10-15 이전) 날짜는 율리우스력 JDN 식을 써야 한다. 조선 시대 인물 사주를 다룰 경우 필수. 현재 구현은 그레고리 전용 → **1582-10-15 미만 입력은 거부**할 것.

### 6.1 12시진 경계표 (진태양시 기준) — 12행 전체

| 시지 idx | 시지 | 한글 | 시작 | 끝 | 판정식 t=h*60+mi |
|---|---|---|---|---|---|
| 0 | 子 | 자 | 23:00 | 00:59 | `t >= 1380 \|\| t < 60` |
| 1 | 丑 | 축 | 01:00 | 02:59 | `60 <= t < 180` |
| 2 | 寅 | 인 | 03:00 | 04:59 | `180 <= t < 300` |
| 3 | 卯 | 묘 | 05:00 | 06:59 | `300 <= t < 420` |
| 4 | 辰 | 진 | 07:00 | 08:59 | `420 <= t < 540` |
| 5 | 巳 | 사 | 09:00 | 10:59 | `540 <= t < 660` |
| 6 | 午 | 오 | 11:00 | 12:59 | `660 <= t < 780` |
| 7 | 未 | 미 | 13:00 | 14:59 | `780 <= t < 900` |
| 8 | 申 | 신 | 15:00 | 16:59 | `900 <= t < 1020` |
| 9 | 酉 | 유 | 17:00 | 18:59 | `1020 <= t < 1140` |
| 10 | 戌 | 술 | 19:00 | 20:59 | `1140 <= t < 1260` |

```ts
export function hourZhiIndex(h: number, mi: number): number {
  const t = h * 60 + mi;
  if (t >= 23 * 60) return 0;
  return Math.floor((t + 60) / 120) % 12;
}
```

> ⚠️유파차이 — **경계를 23:30/01:30 으로 30분 밀어 쓰는 유파**가 있다. 이는 한국 표준시(135°E)와 서울 경도(127°E)의 32분 차이를 시진 경계 쪽에 흡수시킨 방식이다.
> - **선택 A(본 문서 확정)**: 진태양시로 변환한 뒤 23:00/01:00 정각 경계 → 물리적으로 정확, 출생지별로 다름.
> - **선택 B**: 표준시 그대로 두고 경계를 23:30~01:30 으로 이동 → 서울 근처에서는 A와 거의 동일하지만 제주/독도/해외 출생에서 어긋난다.
> - 결과 차이: 서울(127°E) 출생 11:20 KST → A는 진태양시 10:48 → **巳시**, B는 표준시 11:20 → 11:30 미만이라 **巳시**. 11:40 KST → A 11:08 → **午시**, B → **午시**. 대체로 일치하나 경도가 135에서 멀어질수록(예: 신안 126.1°E, 33분+) 경계 ±10분 구간에서 갈린다.

## 9. 진태양시(眞太陽時) 변환

```ts
utcMillis = Date.UTC(y, mo-1, d, h, mi) − (stdOffsetMin + dstMin) × 60000
tstMillis = utcMillis + (경도° × 4 + 균시차(분)) × 60000
```

- 경도 보정: `(경도 − 135) × 4분`. 서울 126.978°E → **−32.1분**. 부산 129.08°E → −23.7분. 신안 126.10°E → −35.6분.
- 균시차(Equation of Time): 최대 ±16분. Meeus 공식 구현 제공(`equationOfTime`).

### 9.1 한국 표준자오선 변경 이력 (분기표)

| 1912-01-01 ~ 1954-03-20 | 135°E | UTC+9:00 |
| 1954-03-21 ~ 1961-08-09 | 127°30′E | UTC+8:30 |
| 1961-08-10 ~ 현재 | 135°E | UTC+9:00 |

### 9.2 한국 서머타임 (−1시간 보정)

## 11. 전체 구현 — `calcFourPillars(trueSolarTime): Pillars`

파일: `scratchpad/calc-lab/four-pillars/fourPillars.ts` (실행 검증 완료)

```ts
export type JasiRule = "yajasi" | "johjasi" | "yajasi-nextstem";

export interface TrueSolarTime {
  y: number; mo: number; d: number; h: number; mi: number; s?: number;
  utcMillis: number;   // 동일 순간의 절대시각 (절기 비교에 사용)
}

export interface Pillars {
  year: Pillar; month: Pillar; day: Pillar; hour: Pillar;
  yearForSaju: number;  monthOrder: number;   // 0=寅 … 11=丑
  jeol: { han: string; ko: string; enteredUtcMillis: number };
  dayJdn: number; jasiRule: JasiRule; gz8: string;
  boundaryWarning: boolean; minutesFromJeol: number;
}

export const OHODUN  = [2,4,6,8,0,2,4,6,8,0];   // (2g+2) mod 10
export const OSEODUN = [0,2,4,6,8,0,2,4,6,8];   // (g mod 5)*2

export function calcFourPillars(
  t: TrueSolarTime,
  opts: { jasiRule?: JasiRule } = {}
): Pillars {
  const jasiRule: JasiRule = opts.jasiRule ?? "yajasi";

  // === 1) 월주: 절입 구간 결정 (절대시각 기준) ===
  const cands: { i: number; ms: number; gy: number }[] = [];
  for (let gy = t.y - 1; gy <= t.y + 1; gy++)
    jeolTimes(gy).forEach((ms, i) => cands.push({ i, ms, gy }));
  cands.sort((a, b) => a.ms - b.ms);
  let cur = cands[0];
  for (const c of cands) if (c.ms <= t.utcMillis) cur = c; else break;

  const monthOrder = cur.i;                    // 0=寅 … 11=丑
  const monthZhi   = JEOL[monthOrder].zhi;

  // === 2) 연주: 입춘 절입 기준. 小寒(order 11)은 직전 사주년 소속 ===
  const yearForSaju = monthOrder === 11 ? cur.gy - 1 : cur.gy;
  const yGan = mod(yearForSaju - 4, 10);
  const yZhi = mod(yearForSaju - 4, 12);

  // === 3) 월간: 오호둔 ===
  const mGan = mod(OHODUN[yGan] + monthOrder, 10);

  // === 4) 일주: JDN offset −11 ===
  let jdn = jdnNoon(t.y, t.mo, t.d);
  const hzIdx     = hourZhiIndex(t.h, t.mi);
  const isLateZi  = t.h === 23;                      // 23:00~23:59
  if (jasiRule === "johjasi" && isLateZi) jdn += 1;  // 子初換日
  const dIdx60 = mod(jdn - 11, 60);
  const dGan = dIdx60 % 10, dZhi = dIdx60 % 12;

  // === 5) 시간: 오서둔 ===
  let stemDayGan = dGan;
  if (jasiRule === "yajasi-nextstem" && isLateZi) stemDayGan = mod(dGan + 1, 10);
  const hGan = mod(OSEODUN[stemDayGan] + hzIdx, 10);

  const P = {
    year:  mkPillar(yGan, yZhi),
    month: mkPillar(mGan, monthZhi),
    day:   mkPillar(dGan, dZhi),
    hour:  mkPillar(hGan, hzIdx),
  };
  const minutesFromJeol = (t.utcMillis - cur.ms) / 60000;
  return { ...P, yearForSaju, monthOrder,
    jeol: { han: JEOL[monthOrder].han, ko: JEOL[monthOrder].ko, enteredUtcMillis: cur.ms },
    dayJdn: jdn, jasiRule,
    gz8: `${P.year.gz} ${P.month.gz} ${P.day.gz} ${P.hour.gz}`,
    boundaryWarning: minutesFromJeol < BOUNDARY_GUARD_MIN,
    minutesFromJeol: Math.round(minutesFromJeol) };
}
```

