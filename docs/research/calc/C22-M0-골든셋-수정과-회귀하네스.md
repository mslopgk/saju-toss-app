### 3.2 정정 2 — 대운수 클램프

`golden-set.json > conventions.daewoonNumber` 원문:

```
한국식 = max(1, round(floor(Δ일)/3)) — **클램프 필수**. Δ = 순행이면 다음 節까지, 역행이면 직전 節부터.
floor 선적용이 핵심이며 클램프가 없으면 275건 중 216건(78.5%)만 통과한다(Δ<3일 케이스 59건이 0 vs 기대 1). C00 §S6-2(b).
```

실측 (`정정②-b`):

| 지표 | 값 |
|---|---|
| `max(1, round(floor(Δ)/3))` 통과 | **275 / 275** |
| 클램프 제거 `round(floor(Δ)/3)` 통과 | **216 / 275** (78.55%) |
| 클램프가 구제하는 건수 | **59** — 전부 `raw === 0` |
| `floor(Δ일) < 3` 인 케이스 | **65** |

> **문구 정정**: 「Δ<3일 케이스 59건」은 부정확하다. `floor(Δ)<3` 은 **65건**이고, 그중 `floor(Δ)=2` 인 **6건**은 `round(2/3)=1` 이라 클램프 없이도 맞는다. **클램프를 필요로 하는 건수가 59**(= `floor(Δ)∈{0,1}`)다. → `golden-set.json` 과 C00 §3-F2 문구를 정정했다(§8).

```js
// ⚠️ region:'GENERIC' 케이스는 stdOffsetMinutes / dstMinutes 를 **반드시** 넘겨야 한다.
//    안 넘기면 KR_TIMELINE 이 오적용되어 4기둥 4건·대운 1건이 실패한다.
//    `utcOffsetMinutes` 는 골든셋 v1 별칭이므로 stdOffsetMinutes 로 승격해 넘긴다.
const toOpts = (i) => {
  const o = {
    applyTz: i.tzMode === 'historical',
    jasiRule: i.jasiRule,
    longitude: i.longitude,
    region: i.region ?? 'KR',
  };
  if (o.region === 'GENERIC') {
    o.stdOffsetMinutes = i.stdOffsetMinutes ?? i.utcOffsetMinutes;
    o.dstMinutes = i.dstMinutes ?? 0;
    if (typeof o.stdOffsetMinutes !== 'number')
      throw new Error(`${i.date} ${i.time}: region=GENERIC 인데 stdOffsetMinutes/utcOffsetMinutes 가 없다 (MISSING_TZ)`);
  }
  return o;
};
```
