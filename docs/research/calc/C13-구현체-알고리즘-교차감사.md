## 2. 기준 오라클 구축

### 2.1 오라클 1 — Skyfield + JPL DE440s

절기의 정의: **겉보기 태양황경(apparent geocentric ecliptic longitude, 진분점 of date, 광행차·장동 포함) = k × 15°**

```python
# gen_skyfield.py (핵심부)
from skyfield.api import load
from skyfield.framelib import ecliptic_frame
from skyfield.searchlib import find_discrete
import numpy as np

ts = load.timescale()
eph = load('de440s.bsp')
earth, sun = eph['earth'], eph['sun']

def apparent_lon(t):
    lat, lon, dist = earth.at(t).observe(sun).apparent().frame_latlon(ecliptic_frame)
    return lon.degrees

def norm180(x):
    return (np.asarray(x, dtype=float) + 180.0) % 360.0 - 180.0

def solve(target, t0, t1):
    def f(t):
        return norm180(apparent_lon(t) - target) > 0
    f.step_days = 1.0
    times, vals = find_discrete(t0, t1, f)
    return [(tt, vv) for tt, vv in zip(times, vals) if vv]
```

```
## KASI 공표값 == floor(DE440s,분) 94/167   == round(DE440s,분) 164/167
```

### 5.2 두 개의 절기 계산 경로 — 어느 쪽이 호출되는가

```cpp
// src/SSQ.cpp — 달력 배열용(날짜 단위)
long double SSQ::qi_high(long double W) {
    long double t = XL::S_aLon_t2(W) * 36525;          // 저정밀 (최대오차 600초!)
    t = t - dt_T(t) + 8.0 / 24.0;
    long double v = fmod(t + 0.5, 1) * 86400;
    if (v < 1200 || v > 86400 - 1200)                  // 자정 ±20분 이내일 때만
        t = XL::S_aLon_t(W) * 36525 - dt_T(t) + 8.0 / 24.0;   // 고정밀 재계산
    return t;
}

// src/eph.h — Day::getJieQiJD() 가 호출하는 경로
inline long double qi_accurate(long double W) {
    long double t = XL::S_aLon_t(W) * 36525;           // 항상 고정밀
    return t - dt_T(t) + (long double)8.0 / (long double)24.0;
```

```cpp
// src/eph.cpp — 고정밀 반복해
long double S_aLon_t(long double W) {
    long double t, v = 628.3319653318;
    t = (W - 1.75347 - PI) / v; v = E_v(t);
    t += (W - S_aLon(t, 10)) / v; v = E_v(t);
    t += (W - S_aLon(t, -1)) / v;      // n=-1 = 전항(full precision)
```

### 5.3 −16초 편향의 진범 — ΔT 외삽

```cpp
// src/eph.cpp
static constexpr long double dt_at[] = {   // TD - UT1 계산표 (마지막 3구간만 발췌)
    ...
    2000, 63.87, 0.1, 0, 0,
    2005, 64.7, 0.4, 0, 0,   //一次项记为x,则 10x=0.4秒/年*(2015-2005),解得x=0.4
    2015, 69
};

long double dt_ext(long double y, int jsd) {
    long double dy = (y - 1820) / 100;
    return -20 + jsd * dy * dy;            //二次曲线外推
}

long double dt_calc(long double y) {
    long double y0 = 2015;   // 표의 마지막 연도
    long double t0 = 69;     // 그 해의 ΔT
    if (y >= y0) {
        int jsd = 31;        //瑞士星历表jsd=31, NASA网站jsd=32, skmap的jsd=29
        if (y > y0 + 100) return dt_ext(y, jsd);
        long double v  = dt_ext(y, jsd);
        long double dv = dt_ext(y0, jsd) - t0;
        return v - dv * (y0 + 100 - y) / 100;
    }
    ... // 표 내 3차 보간
}
```

### 10.1 진태양시 ON/OFF

manseryeok 의 진태양시 구현 (소스 직독):

```javascript
// node_modules/manseryeok/dist/time/true-solar-time.js
const KST_STANDARD_MERIDIAN = 135;
const KST_OFFSET_MIN = 540;
exports.DEFAULT_LONGITUDE = 127.5;

function resolveInstant(year, month, day, hour, minute, options) {
    const wallMs = Date.UTC(year, month - 1, day, hour, minute, 0);
    if (!options) {
        // 보정 없음: 입력을 KST(UTC+9) 표준시로 간주
        const instantUTCms = wallMs - KST_OFFSET_MIN * MINUTE_MS;
        const apparentMs = instantUTCms + KST_STANDARD_MERIDIAN * 4 * MINUTE_MS; // = wallMs
        return { instantUTCms, apparentMs };
    }
    const longitude = options.longitude ?? exports.DEFAULT_LONGITUDE;
    const applyEoT = options.applyEquationOfTime ?? true;
    const applyDst = options.applyHistoricalDst ?? true;
    const civilOffsetMin = applyDst ? koreaCivilOffsetMin(year, month, day, hour) : KST_OFFSET_MIN;
    const instantUTCms = wallMs - civilOffsetMin * MINUTE_MS;
    const eotMin = applyEoT ? equationOfTimeMinutes(instantUTCms) : 0;
    const apparentMs = instantUTCms + (longitude * 4 + eotMin) * MINUTE_MS;
    return { instantUTCms, apparentMs };
}
```

⚠️ **`applyHistoricalDst` 가 `trueSolarTime` 옵션 객체 안에 들어 있다.** 옵션을 아예 주지 않으면 **표준시 이력(1954~1961 UTC+8:30)과 서머타임도 적용되지 않는다.** 표준시 이력만 원하면 `{longitude:135, applyEquationOfTime:false, applyHistoricalDst:true}` 로 명시해야 한다(본 감사의 `M_tzonly` 열).

## 11. manseryeok 잔여 검증 — C09 §11.5 의 `[미검증]` 3건 해소

### 11.1 야자시 옵션 — 3유파 전부 지원 (해소)

```javascript
// node_modules/manseryeok/dist/pillars.js
/**
 * 지방 진태양시 기준 일주 계산.
 * - midnight: 일주·시주 모두 당일
 * - jasi: 일주·시주 모두 다음날
 * - splitJasi: 일주는 당일, 시주 천간만 다음날
 */
function computeDayPillar(apparentMs, dayBoundary) {
    const d = new Date(apparentMs);
    const baseGanji = ganjiIndexForDate(d.getUTCFullYear(), d.getUTCMonth() + 1, d.getUTCDate());
    const isLateZi = d.getUTCHours() >= 23;
    const nextGanji = (baseGanji + 1) % 60;
    let dayGanji = baseGanji;
    let hourStemGanji = baseGanji;
    if (isLateZi) {
        if (dayBoundary === 'jasi') { dayGanji = nextGanji; hourStemGanji = nextGanji; }
        else if (dayBoundary === 'splitJasi') { hourStemGanji = nextGanji; }
    }
    return { pillar: pillarFromGanji(dayGanji), dayStemIndex: hourStemGanji % 10 };
}
```

**기본값 `'midnight'` = C03 확정 한국 주류(a).** 3유파 전부 지원. `dayBoundary` 를 명시적으로 넘기는 것을 권장(기본값 변경 리스크 회피).

### 11.3 진태양시 상수 — DEFAULT_LONGITUDE 127.5 확인 (해소)
