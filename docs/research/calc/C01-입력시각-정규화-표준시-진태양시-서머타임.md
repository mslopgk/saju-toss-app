## 0. 최종 공식 (확정)

### 0.1 기호 정의

| 기호 | 의미 | 단위 | 부호 규약 |
|---|---|---|---|
| `W` | 입력 벽시계(민간시). 사용자가 말하는 "태어난 시각" | 분 | — |
| `O_std` | 그 순간 법정 **표준시** 오프셋 (DST 제외) | 분 | UTC 동쪽 + |
| `O_dst` | 그 순간 적용된 **서머타임** 가산분 | 분 | 적용 시 **+60** |
| `λ` | 출생지 경도 | 도(°) | 동경 **+**, 서경 **−** |
| `λ_std` | 표준자오선 = `O_std / 4` | 도(°) | — |
| `L` | 경도보정 = `4 × (λ − λ_std)` | 분 | 표준자오선보다 **서쪽이면 음수** |
| `E` | 균시차 = 시태양시 − 평균태양시 | 분 | 11월 초 최대 **+16.5**, 2월 중순 최소 **−14.3** |
| `T` | 진태양시(시태양시, Apparent Solar Time) | 분 | — |

### 0.2 확정 공식

```
UTC        = W − (O_std + O_dst)                     … (1) 순간 확정
LMT        = UTC + 4λ                                … (2) 지방평균태양시
T          = LMT + E                                 … (3) 진태양시

⇒ 벽시계 기준 등가식:
T = W − O_dst + 4·(λ − λ_std) + E
  = W + ΔTotal ,   ΔTotal = −O_dst + L + E           … (4) 최종 확정식
```

**계산 순서(반드시 이 순서)**

```
1) W 를 (O_std, O_dst) 로 해석 → UTC 순간 확정   ← gap/overlap 판정도 여기서
2) λ_std = O_std / 4
3) L = 4 × (λ − λ_std)
4) E = EoT(UTC 순간)                              ← UTC 기준 JD 로 계산
5) ΔTotal = −O_dst + L + E
6) T = W_effective + ΔTotal
      (W_effective = UTC + O_std + O_dst. 갭 보정이 반영된 벽시계)
```

**각 항의 부호 (실측)**

| 항 | 서울(126.99°E, KST+9) 예 | 값 |
|---|---|---|
| `−O_dst` | 1988-09-17 (서머타임 시행 중) | **−60분** |
| `L` | `4 × (126.99 − 135)` | **−32.04분** |
| `E` | 2024-02-12 (연중 최소) | **−14.23분** |
| `E` | 2024-11-03 (연중 최대) | **+16.49분** |
| `ΔTotal` (서머타임 없음) | 연중 범위 | **−46.27분 ~ −15.55분** |

> 서울 기준 총보정 연중 극값 (실행 결과, `extra.ts`):
> 최소 **−46.27분** (2024-02-12), 최대 **−15.55분** (2024-11-03). 진폭 **30.7분**.
> ⇒ "일괄 −30분" 유파는 연중 최대 **±16분** 오차를 갖는다.

## 3. 균시차 (Equation of Time)

### 3.1 [E-1] NOAA / Meeus 고정밀식 — **채택 기본값**

NOAA Global Monitoring Laboratory 태양계산기 공식 소스(`main.js`)에서 그대로 발췌:

```javascript
function calcGeomMeanLongSun(t) {
	var L0 = 280.46646 + t * (36000.76983 + t*(0.0003032))
	while(L0 > 360.0) { L0 -= 360.0 }
	while(L0 < 0.0)   { L0 += 360.0 }
	return L0		// in degrees
}
function calcGeomMeanAnomalySun(t) {
	var M = 357.52911 + t * (35999.05029 - 0.0001537 * t);
	return M;		// in degrees
}
function calcEccentricityEarthOrbit(t) {
	var e = 0.016708634 - t * (0.000042037 + 0.0000001267 * t);
	return e;		// unitless
}
function calcMeanObliquityOfEcliptic(t) {
	var seconds = 21.448 - t*(46.8150 + t*(0.00059 - t*(0.001813)));
	var e0 = 23.0 + (26.0 + (seconds/60.0))/60.0;
	return e0;		// in degrees
}
function calcObliquityCorrection(t) {
	var e0 = calcMeanObliquityOfEcliptic(t);
	var omega = 125.04 - 1934.136 * t;
	var e = e0 + 0.00256 * Math.cos(degToRad(omega));
	return e;		// in degrees
}
function calcEquationOfTime(t) {
	var epsilon = calcObliquityCorrection(t);
	var l0 = calcGeomMeanLongSun(t);
	var e  = calcEccentricityEarthOrbit(t);
	var m  = calcGeomMeanAnomalySun(t);

	var y = Math.tan(degToRad(epsilon)/2.0);
	y *= y;

	var sin2l0 = Math.sin(2.0 * degToRad(l0));
	var sinm   = Math.sin(degToRad(m));
	var cos2l0 = Math.cos(2.0 * degToRad(l0));
	var sin4l0 = Math.sin(4.0 * degToRad(l0));
	var sin2m  = Math.sin(2.0 * degToRad(m));

	var Etime = y * sin2l0 - 2.0 * e * sinm + 4.0 * e * y * sinm * cos2l0
	          - 0.5 * y * y * sin4l0 - 1.25 * e * e * sin2m;
	return radToDeg(Etime)*4.0;	// in minutes of time
}
function calcTimeJulianCent(jd) { return (jd - 2451545.0)/36525.0 }
function getJD(year, month, day) {
	if (month <= 2) { year -= 1; month += 12 }
	var A = Math.floor(year/100)
	var B = 2 - A + Math.floor(A/4)
	var JD = Math.floor(365.25*(year + 4716)) + Math.floor(30.6001*(month+1)) + day + B - 1524.5
	return JD
}
```

수식 형태:

```
T   = (JD − 2451545.0) / 36525                       (율리우스 세기, JD 는 UT 기준)
L₀  = 280.46646 + 36000.76983·T + 0.0003032·T²       (deg, mod 360)
M   = 357.52911 + 35999.05029·T − 0.0001537·T²       (deg)
e   = 0.016708634 − 0.000042037·T − 0.0000001267·T²
Ω   = 125.04 − 1934.136·T                            (deg)
ε₀  = 23° + (26 + (21.448 − 46.8150·T − 0.00059·T² + 0.001813·T³)/60)/60
ε   = ε₀ + 0.00256·cos Ω
y   = tan²(ε/2)

E[분] = 4 · (180/π) · [ y·sin2L₀ − 2e·sinM + 4ey·sinM·cos2L₀
                        − 0.5y²·sin4L₀ − 1.25e²·sin2M ]
```

**정확도**: 초 단위(≤ 몇 초). 사주 용도에서는 사실상 오차 무시.

### 3.2 [E-2] NOAA Fourier 근사식 (`solareqns.PDF` 원문)

```
γ = (2π/365) × (day_of_year − 1 + (hour − 12)/24)     (윤년은 366)

eqtime = 229.18 × ( 0.000075
                  + 0.001868·cos γ  − 0.032077·sin γ
                  − 0.014615·cos 2γ − 0.040849·sin 2γ )   [분]

decl   = 0.006918 − 0.399912·cos γ + 0.070257·sin γ
         − 0.006758·cos 2γ + 0.000907·sin 2γ
         − 0.002697·cos 3γ + 0.00148·sin 3γ               [rad]

time_offset = eqtime + 4×longitude − 60×timezone          [분]
tst         = hr×60 + mn + sc/60 + time_offset            [분]
ha          = tst/4 − 180                                 [deg]
snoon       = 720 − 4×longitude − eqtime                  [분, UTC]
```

**오차(실측)**: NOAA/Meeus 대비 **최대 0.730분(≈44초), 평균 0.284분** (366일 스캔).

### 3.4 [E-4] PVCDROM 간이식 — 다수 사주 라이브러리 채택형

```typescript
// rath/orrery packages/core/src/timezone.ts 원문
function getEquationOfTimeMinutes(year: number, month: number, day: number): number {
  const dayOfYear = getDayOfYear(year, month, day);
  const b = (2 * Math.PI * (dayOfYear - 81)) / 364;
  return 9.87 * Math.sin(2 * b) - 7.53 * Math.cos(b) - 1.5 * Math.sin(b);
}
```

> ⚠️ orrery 는 분모에 **364** 를 쓴다. pvlib 원식은 **365** (`_calculate_simple_day_angle(dayofyear) - (2π/365)*80`).
> 364 를 쓰면 연말로 갈수록 위상이 약 1일 어긋난다.

**오차(실측, 365 분모 기준)**: NOAA/Meeus 대비 **최대 1.070분, 평균 0.435분**. 10월 초에 −1.05분으로 최악.

### 5.3 ⚠️ 자시(子時) 경계 유파

| 유파 | 자시 시작 | 비고 |
|---|---|---|
| **정자시(正子時)** | **23:00** | 12지지 2시간 균등 분할. 23:00 부터 익일 일주 적용 |
| **야자시(夜子時) 30분 시프트** | **23:30** | 나무위키: *"00시 30분을 기준으로 하는 야자시와, 23시 30분부터 익일을 적용하는 정자시가 있다 … 사주가들 사이에서 첨예한 떡밥"* |

```typescript
export const KR_TIMELINE: Segment[] = (() => {
  const segs: Segment[] = KR_STD_SPANS.map(s =>
    ({ fromUTC: s.fromUTC, std: s.offset, dst: 0, label: s.label, source: s.source }));

    const offUTC = wall(...d.endLocal)   - (d.stdOffset + d.save) * MIN;   // 서머타임 벽시계
    segs.push({ fromUTC: onUTC,  std: d.stdOffset, dst: d.save, label:`KDT +${(d.stdOffset+d.save)/60}`, source:`Rule ROK ${d.year}` });
    segs.push({ fromUTC: offUTC, std: d.stdOffset, dst: 0,      label:`KST +${d.stdOffset/60}`,          source:`Rule ROK ${d.year} end` });
  }
  segs.sort((a,b) => a.fromUTC - b.fromUTC);

export function resolveKoreanWallClock(y,mo,d,h,mi): KrResolve {
  const w = wall(y, mo, d, h, mi);
  const probe   = [-36,-12,0,12,36].map(dh => segAtUTC(w + dh*60*MIN));
  const offsets = [...new Set(probe.map(s => s.std + s.dst))];

  const valid: {utc:number; seg:Segment}[] = [];
  for (const off of offsets) {
    const utc = w - off * MIN;
    const seg = segAtUTC(utc);
    if (Math.abs((seg.std + seg.dst) - off) < 1e-9) valid.push({ utc, seg });   // 왕복 검증
  }

  let chosen, gap = false, overlap = false;
  if (valid.length === 0) {
    // 전진 전환 갭: 전환 직전 오프셋 채택 → 벽시계가 갭 길이만큼 앞으로 밀림
    gap = true;
    const off = Math.min(...offsets);
    chosen = { utc: w - off*MIN, seg: segAtUTC(w - off*MIN) };
  } else {
    valid.sort((a,b) => a.utc - b.utc);
    overlap = valid.length > 1;
    chosen  = valid[0];                                                        // prefer-first
  }
  return { stdOffset: chosen.seg.std, dst: chosen.seg.dst, utcMs: chosen.utc, gap, overlap, /* ... */ };
}
```

### 7.3 메인 함수

```typescript
export function normalizeBirthTime(input: NormalizeInput): NormalizeOutput {
  const mode    = input.mode ?? 'TRUE_SOLAR';
  const eotAlgo = input.eot  ?? 'NOAA_MEEUS';
  const region  = input.region ?? 'KR';
  const lon     = input.longitude ?? 126.9900;   // 서울
  const notes: string[] = [];

  // ── 생시 모름 ────────────────────────────────────────────────
  let h = input.hour, mi = input.minute;
  if (input.timeUnknown) {
    const pol = input.unknownPolicy ?? 'THREE_PILLARS';
    if (pol === 'THREE_PILLARS') {
      return { trueSolarTime: null, civilDateForDayPillar: {...}, appliedCorrections: {...} };
    }
    if (pol === 'NOON' || pol === 'ASK') { h = 12; mi = 0; }
  }

  // ── 1단계: 표준오프셋 + DST 확정 → UTC 순간 ──────────────────
  let stdOffset: number, dst: number, utcMs: number;
  if (region === 'KR') {
    const r = resolveKoreanWallClock(input.year, input.month, input.day, h, mi);
    stdOffset = r.stdOffset; dst = r.dst; utcMs = r.utcMs;
    if (r.gap)     notes.push('⚠️ DST spring-forward 갭 — 존재하지 않는 벽시계 시각');
    if (r.overlap) notes.push('⚠️ DST fall-back 오버랩 — 동일 벽시계가 2회 등장(prefer-first)');
  } else {
    stdOffset = input.utcOffsetMinutes ?? 540;
    dst       = input.dstMinutes ?? 0;
    utcMs     = wall(input.year, input.month, input.day, h, mi) - (stdOffset + dst) * MIN;
  }

  // ── 2단계: 경도보정 ─────────────────────────────────────────
  const stdMeridian = stdOffset / 4;
  const lonCorr     = 4 * (lon - stdMeridian);

  // ── 3단계: 균시차 (UTC 기준 JD) ──────────────────────────────
  const utc = new Date(utcMs);
  const jd  = getJD(utc.getUTCFullYear(), utc.getUTCMonth()+1, utc.getUTCDate())
            + (utc.getUTCHours() + utc.getUTCMinutes()/60) / 24;
  const eotVal = eotAlgo === 'NOAA_MEEUS' ? eotNoaaMeeus(jd) : /* ... */;

  // ── 4단계: 모드별 총 보정 ────────────────────────────────────
  let total: number;
  switch (mode) {
    case 'STANDARD':   total = -dst;                        break;
    case 'FIXED_30':   total = -dst - 30;                   break;
    case 'LONGITUDE':  total = -dst + lonCorr;              break;
    case 'TRUE_SOLAR': total = -dst + lonCorr + eotVal;     break;
  }

  // ── 5단계: 적용 (갭 시프트 반영 위해 UTC 에서 되돌림) ─────────
  const effectiveWall = utcMs + (stdOffset + dst) * MIN;
  const t = new Date(effectiveWall + total * MIN);

  return {
    trueSolarTime: { year:t.getUTCFullYear(), month:t.getUTCMonth()+1, day:t.getUTCDate(),
                     hour:t.getUTCHours(), minute:t.getUTCMinutes(), second:t.getUTCSeconds(), iso: /* ... */ },
    civilDateForDayPillar: { /* 진태양시 기준 날짜 */ },
    appliedCorrections: {
      stdOffsetMinutes: stdOffset, standardMeridianDeg: stdMeridian, dstMinutes: dst,
      longitudeMinutes: +lonCorr.toFixed(4), eotMinutes: +eotVal.toFixed(4),
      totalMinutes: +total.toFixed(4), utcInstantISO: new Date(utcMs).toISOString(),
      eotAlgorithm: eotAlgo, mode, notes,
    },
  };
}
```
