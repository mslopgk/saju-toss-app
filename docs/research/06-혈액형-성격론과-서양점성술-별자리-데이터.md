# A. 혈액형 성격론

## A-1. 기원과 확산사 (연표)

| 연도 | 사건 | 세부 |
|---|---|---|
| 1900~1901 | 카를 란트슈타이너(Karl Landsteiner)가 ABO식 혈액형 발견 | 목적은 **수혈 안전성**뿐, 성격과 무관 |
| 1916 | 일본 의사 **하라 키마타(原来復, Hara Kimata)** 가 혈액형-기질 연관 논문 발표 | 혈액형 성격론의 최초 시도 |
| 1927 | **후루카와 다케지(古川竹二, Furukawa Takeji)**, 도쿄여자고등사범학교 교수, 논문 「血液型による気質の研究」(The Study of Temperament Through Blood Type)를 학술지 *『心理学研究』(Psychological Research)* 에 발표 | 영문 위키 기준 **실제 분석 표본은 10~20명 수준**으로 "통계적 일반화 요건 미달". 한국어권에는 "주변 지인 319명 조사"로 알려져 있음 [수치 상충 — 두 숫자 모두 유통 중] |
| 1930년대 | 후루카와가 혈액형을 **입시·군 편성에 활용**하자고 제안 | 일본 우생학 흐름과 결합 |
| 1930년대 후반~1960년대 | 학계 반박으로 사실상 사장 | |
| 1971 | **노미 마사히코(能見正比古, Masahiko Nomi)**, 방송 프로듀서/저널리스트(공학 배경, 의학 비전공)가 『血液型でわかる相性』(*Ketsueki-gata de Wakaru Aisho*, 혈액형으로 알 수 있는 궁합) 출간 → **베스트셀러** | 대중화의 결정적 분기점 |
| 1974 | 노미, **궁합 사례 20,000건** 분석 주장 | 방법론은 "대부분 통제되지 않은 일화 수준(largely uncontrolled and anecdotal)"으로 평가 |
| 1976 | **운동선수 1,000명** 분석 | 동일 비판 |
| 1978 | **정치인 2,000명** 분석 | 동일 비판 |
| 1981 | 노미 마사히코 사망 → 아들 **노미 도시타카(能見俊賢)** 가 사업 승계 | |
| 2004 전후 | **한국에서 대유행** — 영화 「B형 남자친구」(2005) 등 대중문화 결합. 한 조사에서 응답자 **75%** 가 "혈액형과 성격이 밀접한 관계가 있다"고 응답 | 한국어 위키백과 |
| 2008 | **대한혈액학회**가 공식 부정 — "혈액형 성격설을 믿는 곳은 한국과 일본뿐" | 한국어 위키백과 |
| 2014.6 | 九州大学 **縄田健悟(나와타 켄고)** 논문, 『心理学研究』(일본심리학회) 게재 → 대규모 반증 | 아래 A-4 |
| 2017 | 한국갤럽 조사에서 **58%** 가 여전히 "혈액형에 따라 성격 차이가 있다"고 응답 | 2002/2012년 대비 하락 추세 |

**핵심 인사이트:** 혈액형 성격론은 **동아시아 3개국(일본·한국·대만) 한정 문화 현상**이다. 영어권 사용자에게는 통하지 않음 → 앱 다국어 확장 시 이 축은 **한국어/일본어 로케일 전용 기능**으로 설계해야 한다.

BLOOD_GENDER_MOD = {   # (남, 여) → 가산. 미기재 조합은 0

blood_score(male, female) = clamp(base(male, female) + MOD.get((male, female), 0), 0, 100)

**canon 생성 규칙 (C08 §4.1) — 어스펙트 + 원소 + 양태 + 극성 4항 합성**

```
k  = min(|i-j| % 12, 12 - (|i-j| % 12))          # 0..6
A  = {0:+12, 1:-6, 2:+14, 3:-12, 4:+20, 5:-8, 6:+18}[k]
E  = +18 if (i%4)==(j%4)          # 동일 원소
     +12 if ((i-j)%4)==2          # 상보 원소(火↔風, 土↔水)
     -8  otherwise                # 인접 원소(火↔水, 土↔風)
M  = -4 if (i%3)==(j%3) else +4   # 양태
P  = +3 if (i%2)==(j%2) else -3   # 극성
score = clamp(50 + A + E + M + P, 0, 100)
```

## B-3. 태양궁 너머 — 달별자리·상승궁(ASC)

| 요소 | 필요 입력 | 변화 속도 | 구현 난이도 |

| **중천 (MC/Midheaven)** | ASC와 동일 | 동일 | ★★★★★ |

### 상승궁이 왜 어려운가 (위키 Ascendant 확인 사항)
- 정의: **출생 순간 동쪽 지평선에 떠오르던 황도 12궁의 사인**.
- **시간 민감도: 약 4분마다 1° 이동, 약 2시간마다 사인이 바뀐다.** → 출생시각이 30분만 틀려도 사인이 바뀔 수 있다.
- 계산식: **국지 항성시(LST/RAMC) + 지구 자전축 경사(황도경사각 ε ≈ 23.44°) + 관측지 위도** 를 조합한 삼각함수. 사분면 판정을 위해 `atan2` 필요.
- **극지 문제:** 북위/남위 약 66.5°(극권) 이상에서는 지평면과 황도면이 교차하지 않는 구간이 생겨 ASC가 **정의되지 않거나 불연속**이 된다. → 한국(위도 33~38°) 사용자만 대상이면 무시 가능하지만, 글로벌 확장 시 예외 처리 필요.

## C. 4축 통합 설계 메모 (사주 + MBTI + 혈액형 + 별자리)

### C-2. 조합 경우의 수 (콘텐츠 물량 산정)

| 축 | 유형 수 |
|---|---|
| 혈액형 | 4 |
| 태양궁 | 12 |
| MBTI | 16 |
| 사주 일간(천간) | 10 |
| **혈액형 × 별자리** | **48** |
| **혈액형 × 별자리 × MBTI** | **768** |
| 궁합(혈액형 4x4) | 16 (성별 구분 시 16) |
| 궁합(별자리 12x12) | 144 → 대칭이므로 실제 고유값 **7종(어스펙트)** |

> 💡 **콘텐츠 전략:** 768개를 사람이 다 쓸 수 없다. **"축별 문장 조각 + 조합 규칙"** 방식으로 설계하라. 예: `[별자리 원소 문장] + [혈액형 관계스타일 문장] + [MBTI 의사결정 문장]` 3조각 조립 → 12+4+16 = 32개 문장만 쓰면 768 조합 커버.
> 별자리 궁합은 **고유값이 7개(컨정션~오포지션)** 뿐이므로 궁합 해설 텍스트는 **7개만 작성**하면 144칸을 전부 채운다. 여기에 원소 조합(4x4=16) 수식어를 얹으면 자연스러운 변주가 생긴다.

### C-3. 데이터 무결성 테스트 케이스

```js
// 1) 원소별 3개, 특질별 4개 검증

assert(count(signs, s => s.modality === 'cardinal') === 4);

// 2) 같은 원소끼리는 반드시 트라인(120°)
for (const [a, b] of samePairs('element'))
  assert(zodiacCompat(a, b).deg === 120 || a === b);

// 3) 궁합 매트릭스 대칭성
for (a of signs) for (b of signs)

// 4) 혈액형 분포 합 = 100
assert(34 + 28 + 27 + 11 === 100);

// 5) 사인 경계 커버리지: 윤년 포함 366일 전부 정확히 1개 사인에 매핑
for (d of allDatesInYear(2024)) assert(signOf(d) !== null);

// 6) 경계일(커스프) 처리: 4/19, 4/20 모두 결과가 존재해야 함
```
