# 사주명리학 이론 체계 전체 정리 (구현용 규칙표)
> 조사 축: 사주명리학 이론 체계 전체 정리 | 상태: 초안 | 검증도: 중상

이 문서는 "사주 + MBTI + 혈액형 + 별자리" 토스 미니앱(Apps in Toss)에 **알고리즘으로 구현할 도메인 지식**을 규칙표 형태로 정리한 것이다.
모든 표는 코드에 그대로 상수(constant table)로 옮길 수 있도록 인덱스 기준을 명시했다.

**인덱스 규약 (문서 전체 공통)**
- 천간 index: `甲0 乙1 丙2 丁3 戊4 己5 庚6 辛7 壬8 癸9`
- 지지 index: `子0 丑1 寅2 卯3 辰4 巳5 午6 未7 申8 酉9 戌10 亥11`
- 60갑자 index: `0~59`, `stem = idx % 10`, `branch = idx % 12`

## 1. 사주팔자 구성

### 1.1 4주(柱) 8자(字)

| 주(柱) | 천간(위) | 지지(아래) | 산출 기준 | 상징 영역 | 시기(근묘화실) |
|---|---|---|---|---|---|
| 연주(年柱) | 연간 | 연지 | **입춘(立春, 황경 315°) 기준** 해가 바뀜 (설날 아님) | 조상·초년·사회적 뿌리 | 0~15세 |
| 월주(月柱) | 월간 | 월지 | **12절(節) 절입 시각 기준** (음력 월 아님) | 부모·형제·직업·사회궁 | 16~30세 |
| 일주(日柱) | **일간 = 나 자신** | 일지 = 배우자궁 | 율리우스 일수 기반 연속 60갑자 | 자신·배우자 | 31~45세 |
| 시주(時柱) | 시간 | 시지 | 일간 + 출생시각(2시간 단위) | 자식·말년·결과 | 46세~ |

- 8자 = 천간 4 + 지지 4. 여기에 지지 4개의 **지장간**까지 포괄하면 실제 해석 대상 글자는 최대 20자 내외.
- 사주 해석의 축은 **일간(日干)** 하나다. 나머지 7자는 전부 일간과의 관계(십신)로 환원된다.

**※ 체용(體用) 음양 불일치 주의** — 구현 시 반드시 분기해야 하는 지점이다.
- **체(體, 순서 기준)**: 짝수 index(子寅辰午申戌) = 양, 홀수 index(丑卯巳未酉亥) = 음. → 형식적 음양
- **용(用, 지장간 정기 기준)**: 子는 정기가 癸(음수) → **음**, 巳는 정기가 丙(양화) → **양**, 亥는 정기가 壬(양수) → **양**, 午는 정기가 丁(음화) → **음**
- **십신 판정에는 반드시 '용' 기준(지장간 정기의 음양)을 쓰는 유파가 다수**다. 앱은 옵션 플래그(`yinYangMode: 'body' | 'function'`)로 분기 처리 권장.
- 8-codes 06강은 子=양수, 巳=음화, 午=양화, 亥=음수(체 기준)로 표기한다.

**지장간 일수 배분(월률분야, 月律分野)** — 위 표 괄호 안 숫자, 합계 30일 기준.
- 정해 만세력 11강 원문 표에서 亥는 `초기 戊7 / 본기 壬16`만 표기되어 합이 23일로 불완전하다. 통설(戊7·甲7·壬16=30)로 보정하여 기재했다 [미검증].
- 午의 己 배분은 유파에 따라 `丙10/己9/丁11` 또는 `丙10/己10/丁10`으로 갈린다 [미검증].

### 1.4 사주 세우기 알고리즘

**(1) 연주**: 입춘 절입 시각 이전 출생 → 전년도 간지 사용.
`yearStemIdx = (year - 4) % 10`, `yearBranchIdx = (year - 4) % 12` (입춘 보정 후의 year 기준).

**(2) 월지**: 12절(節) 절입 시각으로 결정. 寅월(입춘~경칩), 卯월(경칩~청명) … 순.

**(3) 월간 — 둔월법(遁月法) / 월두법 = 오호둔(五虎遁)**

| 연간 | 寅월 천간 | 寅월 간지 |
|---|---|---|
| 甲, 己 | 丙 | 丙寅 |
| 乙, 庚 | 戊 | 戊寅 |
| 丙, 辛 | 庚 | 庚寅 |
| 丁, 壬 | 壬 | 壬寅 |
| 戊, 癸 | 甲 | 甲寅 |

- 구결: "갑기지년병작수(甲己之年丙作首), 을경지세무위두(乙庚之歲戊爲頭), 병신지세경상거(丙辛之歲庚上居), 정임임인순행류(丁壬壬寅順行流), 무계갑인지상구(戊癸甲寅之上求)"
- 공식: `monthStemIdx = (yearStemIdx * 2 + 2 + (monthBranchIdx - 2 + 12) % 12) % 10`
  - 검증: 甲(0)년 寅월 → `(0+2+0)%10 = 2 = 丙` ✓ / 戊(4)년 寅월 → `(8+2+0)%10 = 0 = 甲` ✓
- ⚠️ chocosd 출처 페이지 fetch 결과는 `갑기→丙寅, 을경→丁寅, 병신→戊寅, 정임→己寅, 무계→庚寅`으로 표기되어 있으나, 이는 구결(무위두=戊, 경상거=庚, 임인=壬, 갑인=甲)과 60갑자 정합성(60갑자에 丁寅·己寅은 존재하나 오호둔 결과가 아님)에 어긋난다. **위 표(丙/戊/庚/壬/甲)가 정본**이다.

**(4) 일주**: 기준일 고정 후 연속 계산. 예) 1900-01-01(양력) = 甲戌일 [미검증] → 실무상 `manseryeok` 라이브러리 사용 권장.
`dayIdx60 = (JDN + offset) % 60`

**(5) 시지**: 2시간 단위. 자시(23:00~01:00)는 야자시(23:00~24:00, 당일 일간 유지)/조자시(00:00~01:00) 논쟁 존재 → 옵션화 필요.

**(6) 시간 — 둔시법(遁時法) / 시두법 = 오서둔(五鼠遁)**

| 일간 | 子시 천간 | 子시 간지 |
|---|---|---|
| 甲, 己 | 甲 | 甲子 |
| 乙, 庚 | 丙 | 丙子 |
| 丙, 辛 | 戊 | 戊子 |
| 丁, 壬 | 庚 | 庚子 |
| 戊, 癸 | 壬 | 壬子 |

- 구결: "갑기환가갑(甲己還加甲), 을경병작초(乙庚丙作初), 병신종무기(丙辛從戊起), 정임경자거(丁壬庚子居), 무계하방발(戊癸何方發) 임자시진도(壬子是眞途)"
- 공식: `hourStemIdx = (dayStemIdx * 2 + hourBranchIdx) % 10`
  - 검증: 甲(0)일 子(0)시 → 0 = 甲 ✓ / 癸(9)일 子시 → `18%10 = 8 = 壬` ✓ / 甲일 午(6)시 → `6 = 庚` → 庚午 ✓

**(7) 시간 보정 (한국 필수)**
- 한국 표준시(KST, UTC+9)는 동경 135° 기준이나 서울은 약 동경 127°. `보정 = (경도 - 135) × 4분` → 서울(126.978°) 약 **-32분**.
- 서머타임 시행 구간(1948~1951, 1955~1960, 1987~1988) 별도 보정 필요 [미검증 — 정확 구간은 KASI 확인 요].
- `manseryeok-js`는 `{ longitude: 129, applyTimeCorrection: true }` 옵션으로 이를 제공한다.

**생성 규칙**
```js
const sexagenary = (i) => STEMS[i % 10] + BRANCHES[i % 12];   // i: 0..59
// 역변환 (간지 → index) : 중국식 나머지정리
const idx60 = (s, b) => (s + 10 * (((b - s) % 12 + 12) % 12 * 6 % 12)) % 60; // 검산 필요
// 실무 안전판: 60개 배열을 미리 생성해 indexOf
```

**공망(空亡, 순중공망) 판정 — 표 없이 계산 가능**
```js
const voidBranch1 = (stemIdx, branchIdx) => ((branchIdx - stemIdx) % 12 + 12 + 10) % 12; // (b - s + 10) mod 12
const voidBranch2 = (v1) => (v1 + 1) % 12;
// 검증: 甲子(0,0) → (0-0+10)%12 = 10 = 戌, 다음 亥 ✓
//       甲戌(0,10) → (10-0+10)%12 = 8 = 申, 다음 酉 ✓
//       癸亥(9,11) → (11-9+10)%12 = 0 = 子, 다음 丑 ✓
```
공망 유형은 3종: **순중공망**(위 계산, 가장 널리 사용), **오행공망**, **사대공망(납음 기준, 천간에만 적용)**.
해석: "뭘 해도 헛되게 돼 버리는 살로, 길흉 모두가 감소하여 무력화"(나무위키). 일주 기준 연지/월지/시지가 공망인지 판정한다.

## 3. 오행(五行) 관계

### 3.1 상생(相生) / 상극(相剋)

```
상생: 木 → 火 → 土 → 金 → 水 → 木   (목생화, 화생토, 토생금, 금생수, 수생목)
상극: 木 → 土 → 水 → 火 → 金 → 木   (목극토, 토극수, 수극화, 화극금, 금극목)
```

| 主 \ 客 | 木 | 火 | 土 | 金 | 水 |
|---|---|---|---|---|---|
| **木** | 비화(比和) | 생(生) | 극(剋) | 피극(被剋) | 피생(被生) |
| **火** | 피생 | 비화 | 생 | 극 | 피극 |
| **土** | 피극 | 피생 | 비화 | 생 | 극 |
| **金** | 극 | 피극 | 피생 | 비화 | 생 |
| **水** | 생 | 극 | 피극 | 피생 | 비화 |

```js
const E = ['木','火','土','金','水'];          // index 0..4
const generates = (a, b) => (a + 1) % 5 === b;  // a生b
const controls  = (a, b) => (a + 2) % 5 === b;  // a剋b
```
- 상모(相侮, 반극): 극을 당하는 쪽이 오히려 강하면 반격. 예) 木이 왕성하면 金이 木을 극하려다 상함 → 신강/신약 가중치 계산 시 반영 가능 [미검증].

### 4.1 도출 규칙 (완전 알고리즘화 가능)

> "일간과 오행·음양이 모두 같으면 비견, 오행은 같으나 음양이 다르면 겁재" (한국어 위키백과 십성)

```js
function tenGod(dayStem, target) {          // 둘 다 {element:0..4, yang:boolean}
  const same = dayStem.yang === target.yang;
  if (dayStem.element === target.element)                 return same ? '비견' : '겁재';
  if ((dayStem.element + 1) % 5 === target.element)       return same ? '식신' : '상관';
  if ((dayStem.element + 2) % 5 === target.element)       return same ? '편재' : '정재';
  if ((target.element + 2) % 5 === dayStem.element)       return same ? '편관' : '정관';
  if ((target.element + 1) % 5 === dayStem.element)       return same ? '편인' : '정인';
}
```

**적용 대상**: 연간·월간·시간(3개) + 연지·월지·일지·시지의 **지장간 정기**(4개) = 7개. 정밀 모드에서는 지장간 여기/중기까지 가중 반영.

### 4.3 격국(格局) — 내격 10격

**판정 순서** (정해 만세력 16강)
1. 월지 **정기(본기)**가 천간에 투간(透干)되었는가? → 그 십신이 격
2. 아니면 월지 **중기**가 투간? → 그 십신이 격
3. 아니면 월지 **여기(초기)**가 투간? → 그 십신이 격
4. 아무것도 투간 안 됨 → 월지 정기의 십신을 그대로 격으로

격 이름: 비견격/겁재격(→건록격·양인격으로 대체되기도), 식신격, 상관격, 정재격, 편재격, 정관격, 편관격(칠살격), 정인격, 편인격.
외격(종격 등)은 별도 — 종왕격/종강격/종아격/종재격/종살격.

```js
// 투간 = 지장간 글자와 동일한 천간이 연간/월간/시간에 존재
function getGeokguk(monthBranch, stems /* [year, month, hour] */, dayStem) {
  const hidden = HIDDEN_STEMS[monthBranch];             // [여기, 중기, 정기]
  for (const h of [hidden.main, hidden.mid, hidden.residual]) {
    if (h && stems.includes(h)) return tenGod(dayStem, h) + '격';
  }
  return tenGod(dayStem, hidden.main) + '격';
}
```

## 5. 십이운성(十二運星) / 포태법

### 5.1 12단계

`절(絶) → 태(胎) → 양(養) → 장생(長生) → 목욕(沐浴) → 관대(冠帶) → 건록(建祿) → 제왕(帝旺) → 쇠(衰) → 병(病) → 사(死) → 묘(墓)`

인생 주기 은유: 절=무(無) → 태=잉태 → 양=태아 → 장생=출생 → 목욕=유아 → 관대=청소년 → 건록=사회진출 → 제왕=전성기 → 쇠=쇠퇴 → 병=노쇠 → 사=사망 → 묘=무덤.

### 5.2 도출 규칙 (표 대신 공식으로)

- **양간(甲丙戊庚壬)**: 장생지에서 지지 **순행**(index +1)
- **음간(乙丁己辛癸)**: 장생지에서 지지 **역행**(index -1)

| 일간 | 장생지 | 방향 |
|---|---|---|
| 甲 | 亥(11) | 순행 |
| 乙 | 午(6) | 역행 |
| 丙 | 寅(2) | 순행 |
| 丁 | 酉(9) | 역행 |
| 戊 | 寅(2) | 순행 |
| 己 | 酉(9) | 역행 |
| 庚 | 巳(5) | 순행 |
| 辛 | 子(0) | 역행 |
| 壬 | 申(8) | 순행 |
| 癸 | 卯(3) | 역행 |

```js
const LONGSAENG = [11, 6, 2, 9, 2, 9, 5, 0, 8, 3];  // 천간 index 순
const STAGES = ['장생','목욕','관대','건록','제왕','쇠','병','사','묘','절','태','양'];
function twelveStage(stemIdx, branchIdx) {
  const dir = stemIdx % 2 === 0 ? 1 : -1;
  const step = (((branchIdx - LONGSAENG[stemIdx]) * dir) % 12 + 12) % 12;
  return STAGES[step];
}
```

```js
// 기준지지(연지 또는 일지)가 속한 삼합의 생지(장생지) 구하기
const SAMHAP_BIRTH = { 寅:2, 午:2, 戌:2, 申:8, 子:8, 辰:8, 巳:5, 酉:5, 丑:5, 亥:11, 卯:11, 未:11 };
const SINSAL12 = ['겁살','재살','천살','지살','연살','월살','망신살','장성살','반안살','역마살','육해살','화개살'];
function sinsal12(baseBranch, targetBranch) {
  const start = (SAMHAP_BIRTH[baseBranch] + 9) % 12;      // 겁살 위치 = 생지 - 3
  return SINSAL12[((targetBranch - start) % 12 + 12) % 12];
}
// 검증: base=午(火局, 생지 寅=2) → start = 11 = 亥 → 亥가 겁살 ✓, 申은 (8-11+12)%12=9 → 역마살 ✓
```

## 8. 일간 중심 해석 · 신강/신약 판정 · 용신 도출

### 8.1 신강/신약 판정 3요소

| 요소 | 정의 | 판정 |
|---|---|---|
| **득령(得令)** | 월지가 일간을 돕는가 | 월지가 인성·비겁 오행 → 득령 / 식상·재성·관성 → **실령** |
| **득지(得地)** | 일지가 일간을 돕는가 | 일지가 인성·비겁 → 득지 / 그 외 → **실지** |
| **득세(得勢)** | 나머지 자리에 우군이 많은가 | 인성·비겁이 2~3개 이상 → 득세 / 부족 → **실세** |

- 3개 모두 충족 → **극신강(very_strong)**
- 2개 충족 → 신강(strong)
- 1개 → 중화 근처(medium)
- 0~1개 + 실령 → 신약(weak) / 극신약(very_weak)
- **월지 비중이 가장 크다** (일반적으로 전체 세력의 30~40% 가중치 부여) [미검증 — 수치는 자체 설계]

### 8.2 용신(用神) 도출 5법

| 방법 | 적용 상황 | 규칙 |
|---|---|---|
| **① 억부(抑扶)용신** — 가장 많이 사용 | 대부분 | 신강: 인성 多 → **재성/식상** 용신 / 비겁 多 → **관성** 용신<br>신약: 관성 多 → **인성** / 식상 多 → **인성** / 재성 多 → **비겁** |
| **② 조후(調候)용신** | 사주가 지나치게 덥거나 추울 때 (巳午未월 火多 / 亥子丑월 水多) | "더운 사주는 추운 기운을, 추운 사주는 더운 기운을 용신으로" |
| **③ 통관(通關)용신** | 상극 두 오행이 팽팽할 때 | 강한 오행이 生하는 오행을 용신으로 삼아 相生 흐름 완성 (예: 木 vs 土 대립 → 火로 통관) |
| **④ 병약(病藥)용신** | 삼합/방합으로 특정 오행 국(局)이 형성될 때 | 그 오행 = 병(病), 이를 剋制하는 천간의 오행 = 약(藥) = 용신 |
| **⑤ 종격(從格)용신** | 억부 취용 불가(일간이 완전 고립) | 가장 강한 세력을 따름 — 종왕격/종강격/종아격/종재격/종관(살)격 |

### 8.3 희신/기신/구신/한신 (용신 확정 시 자동 결정)

| 구분 | 정의 | 길흉 |
|---|---|---|
| **용신(用神)** | 나에게 가장 필요한 오행 | 大吉 |
| **희신(喜神)** | 용신을 **生**하는 오행 | 吉 |
| **기신(忌神)** | 용신을 **剋**하는 오행 | 大凶 |
| **구신(仇神)** | 희신을 **剋**하는 오행 | 凶 |
| **한신(閑神)** | 용신·희신과 무관한 오행 | 약간 흉(중립) |

> 단서: 식상·인성이 용신일 때는 역(逆)의 논리가 적용된다 (정해 만세력 15강).

```js
function deriveSpirits(yongsin /* 0..4 */) {
  return {
    yongsin,
    huisin: (yongsin + 4) % 5,  // 용신을 生하는 오행
    gisin:  (yongsin + 3) % 5,  // 용신을 剋하는 오행
    gusin:  (yongsin + 2) % 5,  // 희신을 剋하는 오행
    hansin: (yongsin + 1) % 5   // 나머지
  };
}
// 검증: 용신=木(0) → 희신 水(4) ✓, 기신 金(3) ✓, 구신 土(2)[土剋水] ✓, 한신 火(1) ✓
```

### 9.2 대운수(大運數) 계산

```
순행(양남/음녀): 생일시각 → 다음 절(節) 절입 시각까지의 일수
역행(음남/양녀): 직전 절(節) 절입 시각 → 생일시각까지의 일수

대운수 = round(일수 / 3)          // 3일 = 1년
- 소수점은 반올림 (1일 남으면 버림, 2일 남으면 올림)
- 결과가 0이면 1로 보정
```
- `manseryeok`(yhj1024) 도 "반올림 방식으로 대운수 결정"이라고 명시.
- 정밀 모드: 시·분까지 반영해 `일수 = (절입 timestamp − 출생 timestamp) / 86400000`, `대운수 = 일수/3` 을 실수로 두고 첫 대운 **시작 나이 + 개월**까지 산출 가능.
- 대운 1주기 = **10년**. 대운수 n이면 n세 ~ n+9세가 1운, n+10 ~ n+19세가 2운 …

```js
function calcDaewoon({ birth, monthPillarIdx60, yearStemIdx, gender, prevJieqi, nextJieqi }) {
  const forward = (yearStemIdx % 2 === 0) === (gender === 'male');
  const ms = forward ? (nextJieqi - birth) : (birth - prevJieqi);
  const startAge = Math.max(1, Math.round(ms / 86400000 / 3));
  return Array.from({ length: 10 }, (_, k) => ({
    age: startAge + k * 10,
    ganji: SEXAGENARY[(((monthPillarIdx60 + (forward ? k + 1 : -(k + 1))) % 60) + 60) % 60]
  }));
}
```

| 조합 | 화(化)하는 오행 | 비고 |
|---|---|---|
| 子 + 丑 | 土 | |
| 寅 + 亥 | 木 | |
| 卯 + 戌 | 火 | |
| 辰 + 酉 | 金 | |
| 巳 + 申 | 水 | 巳申은 합이면서 동시에 형·파 — 삼중 관계 |
| 午 + 未 | 火 | 일부 유파는 "합하되 화하지 않음(合而不化)" |

규칙: `(a + b) % 12 === 1` (子0+丑1=1, 寅2+亥11=13%12=1, 卯3+戌10=13%12=1, 辰4+酉9=13%12=1, 巳5+申8=13%12=1, 午6+未7=13%12=1) → **한 줄 판정 가능**.

### 10.2 삼합(三合) — 4조합 (사회적 결속, 가장 강력)

| 조합 | 局(국) | 생지(장생) | 왕지(제왕) | 고지(묘) |
|---|---|---|---|---|
| 亥·卯·未 | 木局 | 亥 | 卯 | 未 |
| 寅·午·戌 | 火局 | 寅 | 午 | 戌 |
| 巳·酉·丑 | 金局 | 巳 | 酉 | 丑 |
| 申·子·辰 | 水局 | 申 | 子 | 辰 |

- **반합(半合)**: 왕지 포함 2글자만 있어도 성립 (亥卯, 卯未 등). 왕지 없는 亥未는 세력 약함.
- 지지 index 기준 서로 **4칸 간격**: `(a+4)%12 === b`.

### 10.3 방합(方合) — 4조합 (계절·혈연 결속)

| 조합 | 局 | 계절 |
|---|---|---|
| 寅·卯·辰 | 木局 | 봄(東方) |
| 巳·午·未 | 火局 | 여름(南方) |
| 申·酉·戌 | 金局 | 가을(西方) |
| 亥·子·丑 | 水局 | 겨울(北方) |

### 10.4 지지충(地支沖) — 6조합

`子↔午, 丑↔未, 寅↔申, 卯↔酉, 辰↔戌, 巳↔亥`
규칙: `(a + 6) % 12 === b` → 정반대 위치.

| 충 | 오행 대립 | 전형적 해석 |
|---|---|---|
| 子午충 | 水↔火 | 감정 기복, 이동, 심장·신장 |
| 丑未충 | 土↔土 (붕충) | 재물·문서 충돌, 형제 갈등 |
| 寅申충 | 木↔金 | 교통·이동·수술 |
| 卯酉충 | 木↔金 | 배신·수술·인간관계 절단 |
| 辰戌충 | 土↔土 (붕충) | 창고 열림(개고), 변동 |
| 巳亥충 | 火↔水 | 역마성 이동, 구설 |

### 10.5 형(刑)

| 유형 | 조합 | 해석 |
|---|---|---|
| **삼형 — 인사신(寅巳申)** | 寅→巳, 巳→申, 申→寅 (무은지형, 無恩之刑) | 은혜를 원수로, 배신, 관재 |
| **삼형 — 축술미(丑戌未)** | 丑→戌, 戌→未, 未→丑 (지세지형, 恃勢之刑) | 세력 믿고 다툼, 형벌 |
| **상형 — 자묘(子卯)** | 子↔卯 (무례지형, 無禮之刑) | 예의 없음, 성(性) 문제 |
| **자형(自刑, 병존)** | 辰辰, 午午, 酉酉, 亥亥 | 스스로를 형함, 자책·자해 |

### 10.6 육해(六害) — 6조합

`子↔未, 丑↔午, 寅↔巳, 卯↔辰, 申↔亥, 酉↔戌`
규칙: `(a + b) % 12 === 7` (子0+未7=7, 丑1+午6=7, 寅2+巳5=7, 卯3+辰4=7, 申8+亥11=19%12=7, 酉9+戌10=19%12=7) → 한 줄 판정.
의미: 합을 방해함(육합 상대의 충). 가족·가까운 사이의 은근한 손상.

### 10.7 육파(六破) — 6조합

`子↔酉, 丑↔辰, 寅↔亥, 卯↔午, 巳↔申, 戌↔未`
의미: 깨뜨림. 중도 좌절, 계약 파기. 寅亥·巳申은 합이면서 파 → 해석 상충 주의.

### 10.8 암합(暗合) / 암명합 (정해 만세력 13강 수록)

| 암합(지지↔지지, 7종) | 결과 |
|---|---|
| 寅丑 / 寅未 | 土 |
| 卯申 | 金 |
| 巳酉 | 水 |
| 午亥 | 木 |
| 戌子 / 辰子 | 火 |

| 암명합(천간↔지지, 4종) | 결과 |
|---|---|
| 壬 ↔ 午 | 木 |
| 戊 ↔ 子 | 火 |
| 丁 ↔ 亥 | 木 |
| 辛 ↔ 巳 | 水 |

> 암합/암명합은 지장간끼리의 천간합에서 유도된다. 유파에 따라 목록이 다르다 [미검증].

### 10.9 천간합(天干合) — 5조합 / 천간충

| 천간합 | 화(化) 오행 | 별칭 | 궁합 의미 |
|---|---|---|---|
| 甲 + 己 | 土 | 중정지합(中正之合) | 안정감·신뢰 |
| 乙 + 庚 | 金 | 인의지합(仁義之合) | 강한 이끌림 |
| 丙 + 辛 | 水 | 위제지합(威制之合) | 지적·우아함 |
| 丁 + 壬 | 木 | 음란지합(淫亂之合) | 낭만적 감성 |
| 戊 + 癸 | 火 | 무정지합(無情之合) | 열정·역동성 |

규칙: `(a + 5) % 10 === b` (甲0+5=5=己 ✓, 乙1+5=6=庚 ✓ …) → 한 줄 판정.
합화(合化) 조건: 월지가 化하는 오행을 지원해야 진짜 합화. 아니면 합거(合去, 묶이기만 함) [미검증].

**천간충 — 4충(정통설)**: 甲庚충, 乙辛충, 丙壬충, 丁癸충 (方位상 대척점: 木↔金, 水↔火)
- 戊·己(土)는 중앙이라 충 없음. 음양이 같은 극(剋) 관계를 전부 충으로 보아 9개로 세는 유파도 존재.
- 규칙: `(a + 6) % 10 === b` 이면서 둘 다 土가 아닐 것.

### 10.10 관계 우선순위 (충돌 시 해석 규칙)

```
1. 방합 > 삼합 > 육합         (세력 크기)
2. 합 > 충                     (합이 충을 해소: 貪合忘沖)
3. 충 > 형 > 파 > 해          (강도)
4. 인접(옆자리) > 격지(떨어진 자리)   — 연-월, 월-일, 일-시가 우선
5. 삼합/방합 결성 시 해당 오행 세력을 신강/신약 스코어에 +2.0 가중 [미검증, 자체 설계]
```

## 11. 궁합(宮合) 판정 로직

### 11.1 겉궁합 vs 속궁합

| 항목 | 겉궁합(外宮合) | 속궁합(內宮合) |
|---|---|---|
| 사용 정보 | **연지(띠) 1글자** | **사주 8글자 전체** |
| 필수 입력 | 생년만 | 생년·월·일·시 |
| 판정 | 12지지의 삼합·육합·충 관계만 | 오행 분포 + 일주 합충 + 십신 + 대운 |
| 정확도 | 낮음 (8글자 중 1글자) | 높음 |
| 비중 | "첫인상, 집안 어른들의 시선 정도" | 실질 관계의 핵심 |

### 11.2 5단계 판정 프로세스 (사자사주)

| 단계 | 내용 | 판정 |
|---|---|---|
| 1 | **일간 확인** | 두 사람의 일간(=본체) 파악 |
| 2 | **일간합(천간합) 여부** | 5합 중 성립 시 "서로에게 자연스럽게 끌리는 인연" (최고 가점) |
| 3 | **오행 균형 비교** | 한 오행 4개 이상 = 과다 판정 / 합산 시 고른 분포 여부 / 상대가 내 부족 오행을 채워주는 상보 구조. **"상극이라도 과다한 오행을 억제해주면 오히려 좋은 궁합"** |
| 4 | **일지 합충형파** | 육합·삼합·방합 = 긍정 / 충·형·원진 = 주의. "충이 있어도 다른 간지가 해소하면 영향 감소" |
| 5 | **십신 분석(배우자성)** | 남성 사주의 **재성**, 여성 사주의 **관성**이 배우자. 상대 일간이 내 사주에서 그 십신이면 자연스러운 인연 구조 |

### 11.4 궁합 판정 코드 스켈레톤

```ts
interface Saju { year: Pillar; month: Pillar; day: Pillar; hour: Pillar; gender: 'M'|'F'; }
interface Pillar { stem: number; branch: number; }  // 0-based index

function compatibility(a: Saju, b: Saju) {
  let score = 50; const reasons: string[] = [];

  if ((a.day.stem + 5) % 10 === b.day.stem) { score += 20; reasons.push('일간 천간합'); }
  if ((a.day.branch + 4) % 12 === b.day.branch || (b.day.branch + 4) % 12 === a.day.branch)
    { score += 18; reasons.push('일지 삼합(반합)'); }
  if ((a.day.branch + b.day.branch) % 12 === 1) { score += 15; reasons.push('일지 육합'); }
  if ((a.day.branch + 6) % 12 === b.day.branch) { score -= 15; reasons.push('일지 충'); }
  if (WONJIN.has(key(a.day.branch, b.day.branch))) { score -= 18; reasons.push('원진살'); }

  // 오행 보완 (8글자 → 오행 카운트 벡터)
  const va = elementVector(a), vb = elementVector(b);
  const merged = va.map((v, i) => v + vb[i]);
  if (merged.every(v => v >= 1)) { score += 12; reasons.push('오행 상호 보완'); }

  return { score: clamp(score, 0, 100), reasons };
}
```

## 14. 구현 시 주의점 체크리스트

1. **입춘 경계** — 1월 1일~2월 3일경 출생자는 전년도 연주. 놓치면 사주 전체가 틀어진다.
2. **절입 시각(시·분)** — 절입 당일 출생자는 시각까지 비교해야 월주가 정확하다.
3. **진태양시 보정** — 서울 기준 −32분. 23:00~23:32, 00:28~01:00 근처 출생자는 시주가 달라진다.
4. **야자시/조자시** — 23:00~24:00을 당일로 볼지 익일로 볼지 유파 분기. 설정 옵션 필수.
5. **체/용 음양** — 子·巳·午·亥의 음양 배정이 유파별로 다르며 **십신 결과가 통째로 바뀐다**. 기본값을 정하고 문서화할 것.
6. **윤달** — 사주는 절기 기준이라 음력 윤달과 무관. 사용자가 "음력 생일"만 알 때만 변환 필요.
7. **서머타임 구간** — 1948~1960년대, 1987~1988년 출생자 [미검증 — KASI 확인 요].
8. **면책 고지** — 국내 앱스토어/토스 심사 및 소비자 보호 관점에서 "재미·엔터테인먼트 목적" 고지 필요.
9. **저작권** — 해석 문구를 기존 사이트에서 복사하지 말 것. 규칙표(사실 데이터)는 저작물성이 낮으나 해설문은 저작물.
10. **유파 편차 표시** — 신살·용신은 유파마다 결과가 다르므로 "이 앱은 ○○ 기준" 명시가 신뢰도에 유리.
