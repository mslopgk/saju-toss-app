# `ait init` 정상 실행 기준

이 문서는 사용자가 제공한 정상 실행 로그를 기준으로 대화형 초기화의 기대 흐름을 기록한다. CLI 버전에 따라 문구나 설정 파일 이름은 달라질 수 있다.

```text
npx ait init
│
◇  프로젝트를 초기화할 템플릿을 선택해주세요.
│  웹 프레임워크
┌  🚀 앱 초기화를 시작합니다
│
◇  Enter app name
│  test
│
◇  앱 이름이 'test'으로 설정되었습니다
│
◇  .gitignore 파일을 업데이트하는 중...
│
◇  웹 번들러의 dev 명령어를 입력해주세요.
│  vite --host 0.0.0.0
│
◇  웹 번들러의 build 명령어를 입력해주세요.
│  tsc -b && vite build
│
◇  granite.config.ts 파일을 생성하는 중...
│
◇  Enter web port
│  5173
│
└  ✨ 초기화가 완료되었습니다!
```

## 운영 규칙

- PTY에서 실행하고 화면에 나타난 각 질문에 차례대로 답한다.
- 템플릿 선택 화면에서 멈춘 것은 파일을 직접 만들어도 된다는 뜻이 아니다.
- 성공 메시지와 종료 코드 0을 확인하기 전에는 초기화 완료라고 보고하지 않는다.
- CLI가 최신 SDK용으로 다른 설정 파일을 만들면 해당 결과를 보존한다.
- TTY 문제는 PTY 재실행으로 해결하고, 설정 파일 수동 작성으로 우회하지 않는다.
